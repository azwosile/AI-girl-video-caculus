## 二次因式

| 编号 | 角色 / 立绘 | 字幕 | 朗读（不同时） |
|---|---|---|---|
| L02 | Llama / l_base | 那 x² + 4 呢？它分解不了。 | 那 x 方加四呢？它在实数里分解不了。 |
| C05 | Claude / c_explain | 不可约二次因式，分子写一次式：(2x² − x + 4)/(x(x² + 4)) = A/x + (Bx + C)/(x² + 4)。 | 不可约的二次因式，分子要写一次式。所以拆成 A 除以 x，加 B x 加 C，除以 x 方加四。 |
| C06 | Claude / c_point | 比较系数：A = 1，B = 1，C = −1。 | 展开比较同次项系数，解得 A 等于一，B 等于一，C 等于负一。 |
