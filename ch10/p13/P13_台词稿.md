## 密切圆

| 编号 | 角色 / 立绘 | 字幕 | 朗读（不同时） |
|---|---|---|---|
| C06 | Claude / c_explain | 例：y = x²。原点 κ = 2，ρ = 1/2；x = 1 处 κ = 2√5/25 ≈ 0.179。 | 例如抛物线 y 等于 x 方。原点处曲率是二，曲率半径是二分之一。到了 x 等于一，曲率只有零点一八左右。 |
| C07 | Claude / c_point | 密切圆：半径为 ρ、贴着曲线的圆，跟曲线弯得一样。 | 贴着曲线、半径等于曲率半径的圆，叫密切圆。它和曲线弯得一模一样。 |
| C08 | Claude / c_explain | 椭圆 x = a cos t，y = b sin t：长轴端点 κ = a/b²，短轴端点 κ = b/a²。摆线拱顶 ρ = 4r。 | 椭圆的长轴端点最弯，曲率是 a 除以 b 方。短轴端点，是 b 除以 a 方。摆线拱顶的曲率半径，是轮子半径的四倍。 |
