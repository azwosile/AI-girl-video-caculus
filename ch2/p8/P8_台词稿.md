## 求导法则：为什么

| 编号 | 角色 / 立绘 | 字幕 | 朗读（不同时） |
|---|---|---|---|
| C09 | Claude / c_point | 求导法则高中都会用，这里只看为什么。乘积法则：长方形两边各长一点，面积多出两条边。 |  |
| C10 | Claude / c_explain | 面积的增量，约等于长乘宽的增量，加上宽乘长的增量；角上那一小块太小，除以 Δx 以后就消失了。 | 面积的增量，约等于长乘宽的增量，加上宽乘长的增量；角上那一小块太小，除以 x 的增量以后就消失了。 |
| C11 | Claude / c_point | 商法则可以由乘积法则推出；幂法则：x 的 n 次方求导，得 n 乘 x 的 n − 1 次方。 | 商法则可以由乘积法则推出；幂法则：x 的 n 次方求导，得 n 乘 x 的 n 减一次方。 |

## 配音后修改

- **C01**：原句的“f 撇 x”误识别，改为“记作 f′，也可以写成 dy 比 dx”（朗读“f 撇”“d y 比 d x”）。复检 0.92 只是 ASR 把 dy/dx 写成大写，内容一致，判为误报。
- **C10**：u、v 被识别成“一/e”，改为“长乘宽的增量，加上宽乘长的增量”，画面矩形标签改为“长 u”“宽 v”。
