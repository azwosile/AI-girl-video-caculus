## 数值核对

| 量 | 值 |
|---|---|
| 追赶各段时间 | 10、1、0.1、0.01 … 秒（每段是上一段的 1/10） |
| 时间总和 | 10 / (1 − 0.1) = 100/9 ≈ 11.111 秒（“十一秒出头”） |
| 直接验算 | 100 米 ÷ (10 − 1) 米/秒 = 100/9 秒 |
| [1, 1 + h] 上的平均速度 | [5(1 + h)² − 5] / h = 10 + 5h：h = 0.1 → 10.5，0.01 → 10.05，0.001 → 10.005 |
| 瞬时速度 | 10 米/秒（取 g = 10 m/s²，画面角落注明） |
| 割线斜率（y = x²，P(1, 1)，Q 横坐标 x） | (x² − 1)/(x − 1) = x + 1：x = 2 → 3，1.5 → 2.5，1.1 → 2.1，1.01 → 2.01 |
| 切线 | y − 1 = 2(x − 1)，即 y = 2x − 1（课件 2.1 例题） |
| JavaScript | `0 / 0` 结果为 `NaN` |
| 史实 | 芝诺（约前 490–前 430）的“阿喀琉斯与乌龟”“飞矢不动”见亚里士多德《物理学》第六卷；“两千四百多年前”成立。极限的严格定义要到 19 世纪（柯西、魏尔斯特拉斯），K03 说的“两千年后才有的工具”指这个 |
