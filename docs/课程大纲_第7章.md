## 3. 分段详案（草案）

### P0｜积分擂台（≈1.5′）
- Grok 开擂台：“第一题，∫sin x cos x dx，谁先答？”
- 大肥鱼：令 u = sin x，得 ½sin²x + C。GPT：令 u = cos x，得 −½cos²x + C。Claude：用二倍角，得 −¼cos 2x + C。
- Grok：“三个答案不一样，这是真的吗？”三条曲线上下平移就能重合，相差的只是常数。求导验算，三个都对。
- 预告后面的题：∫sin³x dx、∫dx/(x² − 1)、∫e^(−x²) dx（“这道题，没人能写出答案”）。本章就是往工具箱里加工具。
- **动画**：A290 擂台计分板 · A291 三条原函数曲线平移重合 · A292 工具箱打开，新工具一件件亮出来
- **随堂**：½sin²x 与 −½cos²x 相差多少？（常数 ½，因为 sin²x + cos²x = 1）

### P1｜速通：基本积分表与两把老工具（≈1.2′，7 章章首表）
- Kimi 一口气背出章首的基本积分表（幂、指数、对数、三角、反三角）。

- **动画**：A293 积分表像卡片墙一张张翻开 · A294 换元 ↔ 链式法则、分部 ↔ 乘积法则 · A295 三种代换三角形
- **随堂**：∫x e^(x²) dx = ？（½e^(x²) + C）

### P2｜分部积分进阶：表格法与循环（≈1.5′，7.1 例 3、例 4）
- ∫x²eˣ dx：分部两次，= eˣ(x² − 2x + 2) + C。表格法（一列求导到 0，一列积分，正负交替）一步写出。
- 豆包：∫eˣ sin x dx 分部两次又回到自己，“越积越回去了，家人们”。Claude：把它当未知数 I，解方程 2I = eˣ(sin x − cos x)，I = ½eˣ(sin x − cos x) + C。
- 陷阱：第二次分部要和第一次选同一类函数当 u，否则一步退回原式。
- **动画**：A296 表格法两列 + 斜箭头 · A297 积分“绕一圈”回到 I 的环形动画 · A298 I 移项解方程
- **随堂**：∫eˣ cos x dx = ？（½eˣ(sin x + cos x) + C）

### P3｜递推公式与华里士公式（≈1.5′，7.1 例 6 + 同济）
- ∫sinⁿx dx = −(1/n)cos x sinⁿ⁻¹x + ((n − 1)/n)∫sinⁿ⁻²x dx。
- 定积分：∫₀^(π/2) sinⁿx dx = ((n − 1)/n)·((n − 3)/(n − 2))·…，偶数结尾乘 π/2，奇数结尾乘 1（华里士公式）。例：n = 4 → 3π/16。
- MiMo 下台阶：n → n − 2 → … 蹦到 0 或 1。
- **动画**：A299 递推台阶 · A300 华里士连乘逐项点亮 · A301 sin⁴x 曲线下面积数值核对
- **随堂**：∫₀^(π/2) sin⁵x dx = ？（8/15）

### P4｜三角积分（一）：正弦与余弦的幂（≈1.5′，7.2 例 1–4）
- 奇次幂：剥出一个，其余用 sin² + cos² = 1：∫cos³x dx = sin x − ⅓sin³x + C。∫sin⁵x cos²x dx 同理。
- 偶次幂：降幂公式 sin²x = (1 − cos 2x)/2：∫₀^π sin²x dx = π/2；∫sin⁴x dx = 3x/8 − ¼sin 2x + (1/32)sin 4x + C。
- 混元按计算器：“偶次就降幂，奇次就剥一个。”
- **动画**：A302 剥一个因子的拆分动画 · A303 sin²x 曲线与 ½ 线、面积对半 · A304 决策树：谁是奇次？
- **随堂**：∫₀^(π/2) sin x cos²x dx = ？（1/3）

### P5｜三角积分（二）：tan、sec 与积化和差（≈1.5′，7.2 例 5、7、8、9）
- sec 偶次：留一个 sec²x 配 d(tan x)：∫tan⁶x sec⁴x dx = (1/7)tan⁷x + (1/9)tan⁹x + C。
- ∫tan³x dx = ½tan²x − ln|sec x| + C。∫sec³x dx = ½(sec x tan x + ln|sec x + tan x|) + C（分部 + 循环，呼应 P2）。Gemini：“这是一个极其漂亮的结论！”
- 积化和差：∫sin 4x cos 5x dx = −(1/18)cos 9x + ½cos x + C。
- **动画**：A305 sec²x 与 d(tan x) 配对 · A306 ∫sec³x 的循环 · A307 两条波叠加成和差
- **随堂**：∫₀^(π/4) sec²x tan x dx = ？（1/2）

### P6｜三角代换进阶与配方（≈1.5′，7.3 例 3、例 7）
- tan 代换：∫dx/(x²√(x² + 4))，令 x = 2 tan θ，结果 −√(x² + 4)/(4x) + C；用三角形把 θ 换回 x。
- 配方：∫x dx/√(3 − 2x − x²)，3 − 2x − x² = 4 − (x + 1)²，令 x + 1 = 2 sin θ，得 −√(3 − 2x − x²) − arcsin((x + 1)/2) + C。
- Mistral：“路不平，先配方修路。”
- **动画**：A308 直角三角形标 x、2、√(x² + 4) · A309 抛物线配方平移 · A310 回代动画
- **随堂**：∫dx/(x² + 2x + 5) = ？（½ arctan((x + 1)/2) + C）

### P7｜部分分式（一）：一次因式（≈1.5′，7.4 例 1、例 2）
- 假分式先做多项式除法：∫(x³ + x)/(x − 1) dx = x³/3 + x²/2 + 2x + 2ln|x − 1| + C。
- 分母分解成不同一次因式：∫(x² + 2x − 1)/(2x³ + 3x² − 2x) dx，2x³ + 3x² − 2x = x(2x − 1)(x + 2)，结果 ½ln|x| + (1/10)ln|2x − 1| − (1/10)ln|x + 2| + C。
- GLM 的掩盖法：求 A 就盖住 x，代 x = 0。
- **动画**：A311 长除法竖式 · A312 分式“拆开”成三块 · A313 掩盖法手掌盖住因子
- **随堂**：∫dx/(x² − 1) = ？（½ln|(x − 1)/(x + 1)| + C）

### P8｜部分分式（二）：重因式与二次因式（≈1.5′，7.4 例 4、例 5）
- 重因式：1/(x(x − 1)²) = 1/x − 1/(x − 1) + 1/(x − 1)²，∫ = ln|x| − ln|x − 1| − 1/(x − 1) + C。
- 不可约二次因式：∫(2x² − x + 4)/(x³ + 4x) dx = ln|x| + ½ln(x² + 4) − ½arctan(x/2) + C。
- Llama：“一项一项写全，不慌不忙。”陷阱：(x − 1)² 只写一项 B/(x − 1)²。
- **动画**：A314 四种情形的模板卡 · A315 待定系数比较方程组 · A316 漏项 ✗ 与写全 ✓ 对照
- **随堂**：(x + 1)/((x − 2)²(x² + 1)) 应该拆成哪几项？（A/(x − 2) + B/(x − 2)² + (Cx + D)/(x² + 1)）

### P9｜有理化代换与万能代换（≈1.5′，7.4 例 9 + 同济）
- 有理化：∫√(x + 4)/x dx，令 u = √(x + 4)，得 2√(x + 4) + 2ln|(√(x + 4) − 2)/(√(x + 4) + 2)| + C。
- 万能代换 t = tan(x/2)：sin x = 2t/(1 + t²)，cos x = (1 − t²)/(1 + t²)，dx = 2dt/(1 + t²)。例：∫₀^(π/2) dx/(1 + sin x + cos x) = ∫₀¹ dt/(1 + t) = ln 2。
- MiniMax 拍变装视频：根号和三角函数都“换装”成有理函数。陷阱：万能代换万能但常常很繁，能用别的方法就别用。
- **动画**：A317 单位圆上 t = tan(x/2) 的几何意义 · A318 换装转场 · A319 繁 vs 简对比
- **随堂**：∫₀¹ dx/(1 + √x) = ？（2 − 2ln 2）

### P11｜积分表、CAS 与算不出来的积分（≈1.2′，7.6 + 7.5 末尾）

### P12｜梯形法则与中点法则（≈1.5′，7.7 例 1、例 2）
- 梯形法则 Tₙ、中点法则 Mₙ。例：∫₁² dx/x，n = 5：T₅ ≈ 0.695635，M₅ ≈ 0.691908；真值 ln 2 ≈ 0.693147。误差 E_T ≈ −0.002488，E_M ≈ 0.001239：中点误差约为梯形的一半，符号相反。
- 误差界：|E_T| ≤ K(b − a)³/(12n²)，|E_M| ≤ K(b − a)³/(24n²)；本题 K = 2，n = 5 时 |E_T| ≤ 0.0067。
- 混元按计算器对比两种方法。
- **动画**：A326 梯形与中点矩形对比 · A327 误差柱状图，n 翻倍误差变 1/4 · A328 凹函数上梯形偏大、中点偏小

### P14｜反常积分进阶：比较判别法（≈1.5′，7.8 例 9、例 10）

- ∫₀^∞ e^(−x²) dx：在 [1, ∞) 上 e^(−x²) ≤ e^(−x)，后者积分 = 1/e，所以收敛；事实上等于 √π/2（高斯积分，只给结果）。
- ∫₁^∞ (1 + e^(−x))/x dx ≥ ∫₁^∞ 1/x dx，发散。Kimi 把第 5 章的 p 积分当标尺。
- 陷阱：比较的方向要对，小的收敛推不出大的收敛。
