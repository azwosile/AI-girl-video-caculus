## 0. 设计原则

| 原则 | 做法 |
|---|---|
| **一条主线：变化率 = 进来的 − 出去的** | 微分方程描述“变化有多快”，而不是“现在是多少”。排队人数、盐水浓度、奶茶温度、电流、兔子和狼，全都是同一个句式：dy/dt = 流入速度 − 流出速度。 |
| **开场的问题中途解决** | P0：dN/dt = 30 − 0.1N，N(0) = 0。P2 用方向场看出队伍会稳定在 300 人，P3 用欧拉法估算，P7 用积分因子解出 N = 300(1 − e^(−0.1t))：10 分钟后约 190 人，约 11 分钟到 200 人，永远不会超过 300 人。 |
| **先看图，再求解** | 每个方程先画方向场或相图，看出平衡解和趋势，再动手解。解出来以后回到图上验证。 |
| **呼应前几章** | 第 3 章指数增长与衰减 → P6；第 7 章部分分式 → P6 解 logistic；第 7 章分部积分、积分表 → P7、P8；第 4 章线性近似 → P3 欧拉法；第 8 章服务器排队 → P0、P7；第 6 章功与弹簧（胡克定律）→ P15。 |

## 3. 分段详案（草案）

### P0｜排队人数会爆吗？（≈1.5′）
- 接第 8 章：服务器繁忙，排队的人还在变多。大肥鱼：“本鲸想知道，十分钟后会排多少人？”
- 千问帮着统计：每分钟新进来 30 人；服务器每分钟处理掉队伍里 10% 的人。
- Claude：我们不知道 N(t) 长什么样，只知道它变化得多快：dN/dt = 30 − 0.1N。这就是一个微分方程：未知的是函数，方程里有它的导数。
- 大肥鱼：“每分钟加 30，十分钟就是 300！”GPT：不对，队伍越长，处理得越多，增长会越来越慢。
- 三个问题留给本章：队伍会无限变长吗？十分钟后多少人？什么时候到 200 人？（P2 看图、P3 估算、P7 精确解出。）
- 随堂一题：队伍有多长时，人数不再变化？答：30 − 0.1N = 0，N = 300。

### P1｜什么是微分方程（≈1.3′）
- 定义：含未知函数及其导数的方程。阶 = 最高阶导数的阶数。例：dP/dt = kP（一阶），mx″ = −kx（二阶，弹簧，P15 再讲）。
- 解 = 代进去使方程成立的函数。y′ = 2x 的解 y = x² + C：一整族曲线（通解）。
- Kimi：初始条件 y(0) = 1 就是“记住开头”，从一族里挑出一条：y = x² + 1（初值问题）。
- 验证解：代入检查。Stewart 9.1 的思路：不会解也可以验证。
- 陷阱：通解里的 C 不能丢；一阶方程一个常数，二阶两个。
- 随堂一题：下面哪些是 y′ = y 的解？eˣ、x²、3eˣ。答：eˣ 和 3eˣ。

### P2｜方向场（≈1.5′）
- 不解方程也能看出解的样子：y′ = F(x, y) 告诉每一点的斜率，在网格上画小线段。
- Gemini：“就像天气 App 的风向图！”顺着小箭头走，就画出一条解曲线。
- Stewart 例 1：y′ = x² + y² − 1。斜率为 0 的点在单位圆上（等斜线）；离圆越远越陡。画出过 (0, 0) 的解曲线。
- 回到 P0：dN/dt = 30 − 0.1N 的斜率只和 N 有关（自治方程）。N < 300 向上，N > 300 向下，N = 300 是水平线（平衡解）。队伍不会爆，会稳定在 300 人。
- 随堂一题：y′ = x + y 在点 (1, 1) 处的斜率？答：2。

### P3｜欧拉法（≈1.5′）
- 方向场的“数值版”：从初始点出发，沿切线走一小步 h，到了新点再重新看斜率。yₙ₊₁ = yₙ + h·F(xₙ, yₙ)。
- Llama：“不慌，一步一步走。”和第 4 章线性近似是同一件事。
- Stewart 例 3：y′ = x + y，y(0) = 1，h = 0.1：y(0.1) ≈ 1.1，y(0.2) ≈ 1.22，y(0.3) ≈ 1.362；精确解 y = 2eˣ − x − 1，y(0.3) ≈ 1.3997。
- 步长减半，误差大约减半；欧拉法会一直偏在曲线的一侧（曲线向上弯时偏低）。
- 回到 P0：h = 1 分钟走几步，看到 N 逐步逼近 300。
- 随堂一题：y′ = y，y(0) = 1，h = 0.5，走一步 y(0.5) ≈ ？答：1.5。

### P4｜可分离变量方程（≈1.5′）
- 形如 dy/dx = g(x)f(y)：y 的放左边，x 的放右边，两边分别积分。
- GLM 把书分成两摞：“y 归 y，x 归 x。”
- Stewart 9.3 例 1：dy/dx = x²/y²，y(0) = 2 ⇒ y²dy = x²dx ⇒ y³/3 = x³/3 + C ⇒ y = ∛(x³ + 8)。
- 推导第 3 章的指数增长：dy/y = k dt ⇒ y = y₀e^(kt)。
- 陷阱：除以 f(y) 时，f(y) = 0 的常数解可能丢掉（例：y′ = xy 的 y = 0）。
- 随堂一题：dy/dx = xy，y(0) = 1 ⇒ ？答：y = e^(x²/2)。

### P5｜混合问题与冷却定律（≈1.5′）
- 混合问题，Stewart 9.3 例 6：5000 L 水里溶了 20 kg 盐；浓度 0.03 kg/L 的盐水以 25 L/min 流入，混匀后以同样速度流出。
  - dy/dt = 流入 − 流出 = 0.75 − y/200 ⇒ y = 150 − 130e^(−t/200)；半小时后 y(30) ≈ 38.1 kg；最终趋于 150 kg。
  - 和 P0 排队方程同一个句式：进来的速度恒定，出去的速度和当前量成正比。
- 冷却定律（同济/Stewart 习题）：dT/dt = −k(T − 20)。千问的热奶茶 90°C，10 分钟后 60°C；什么时候降到 40°C？T − 20 = 70e^(−kt)，k = ln(7/4)/10 ≈ 0.056，t ≈ 22.4 分钟。
- 随堂一题：放很久以后，奶茶是多少度？答：20°C（室温）。

### P6｜从指数增长到 logistic（≈1.5′）
- 豆包的梗在家人们之间传播：一开始 dP/dt = kP，指数爆炸；但人数有上限 M（环境容量）。
- logistic 方程（Stewart 9.4）：dP/dt = kP(1 − P/M)。P 小时 ≈ kP；P 接近 M 时增长停下来。平衡解 P = 0、P = M。
- 分离变量 + 第 7 章部分分式：P = M / (1 + Ae^(−kt))，A = (M − P₀)/P₀。
- Stewart 例 2：k = 0.08，M = 1000，P₀ = 100：P = 1000/(1 + 9e^(−0.08t))；P(40) ≈ 732，P(80) ≈ 985；到 900 约需 t ≈ 54.9。
- 曲线是 S 形，P = M/2 时增长最快（拐点）。
- 随堂一题：M = 1000，人数是多少时传播最快？答：500。

### P7｜一阶线性方程与积分因子（≈1.5′）
- 标准形 y′ + P(x)y = Q(x)。乘上积分因子 I = e^(∫P dx)，左边变成 (Iy)′。
- MiniMax：“加个滤镜！”乘完以后两边积分即可。
- Stewart 9.5 例 1：y′ + 3x²y = 6x²，I = e^(x³) ⇒ y = 2 + Ce^(−x³)。
- 解开场：N′ + 0.1N = 30，I = e^(0.1t) ⇒ N = 300 + Ce^(−0.1t)；N(0) = 0 ⇒ N = 300(1 − e^(−0.1t))。10 分钟后约 190 人；N = 200 时 t = 10 ln 3 ≈ 11 分钟；永远到不了 300。
- 大肥鱼：“所以本鲸的队伍不会爆！”
- 陷阱：先化成标准形（y′ 的系数为 1）再找 P。
- 随堂一题：y′ + 2y = 4 的解，x 很大时趋于多少？答：2。

### P8｜RL 电路（≈1.3′）
- 基尔霍夫定律：L dI/dt + RI = E(t)，一阶线性方程。
- Grok 一拉电闸：“电流怎么不马上到位？”电感阻碍电流变化。
- Stewart 9.5 例 4：R = 12 Ω，L = 4 H，E = 60 V，I(0) = 0 ⇒ I = 5(1 − e^(−3t))；1 秒后约 4.75 A；最终趋于 5 A（= E/R）。
- 例 5：交流电源 E = 60 sin 30t，电流最终跟着正弦振荡（只展示图像）。
- 和 P0、P5 同一个形状：趋于平衡值的指数曲线。
- 随堂一题：L = 2 H，R = 10 Ω，E = 20 V，电流最终是多少？答：2 A。

### P9｜捕食者与猎物（≈1.5′）
- 两个未知函数：兔子 R(t)、狼 W(t)。洛特卡-沃尔泰拉方程：dR/dt = kR − aRW，dW/dt = −rW + bRW。
- MiMo（兔子）：“兔子多了，狼就吃得饱；狼多了，兔子就少了……”
- Stewart 9.6 例 1：k = 0.08，a = 0.001，r = 0.02，b = 0.00002。平衡点：R = 1000，W = 80。
- 相图：在 RW 平面上画 dW/dR，解曲线是闭合的一圈；从 (1000, 40) 出发逆时针转。R(t)、W(t) 都周期振荡，狼的峰值落后于兔子。
- 历史数据：哈德逊湾公司的雪兔与猞猁毛皮记录，周期约 10 年。
- 随堂一题：R = 1000，W = 40 时，兔子在增加还是减少？答：dR/dt = 80 − 40 = 40 > 0，增加。

### P10｜齐次方程（≈1.3′，同济补充）
- 形如 dy/dx = φ(y/x)。换元 u = y/x，y = ux，y′ = u + xu′，化成可分离方程。
- 混元按计算器换元。
- 例：y′ = y/x + x/y，y(1) = 2。u + xu′ = u + 1/u ⇒ u du = dx/x ⇒ u² = 2 ln x + C ⇒ y² = x²(2 ln x + 4)。
- 判别：把 x、y 同时换成 tx、ty，右边不变就是齐次。
- 陷阱：别和下一段的“齐次线性方程”（Q = 0）混淆，同名不同义。
- 随堂一题：y′ = (x² + y²)/(xy) 是齐次方程吗？答：是。

### P11｜伯努利方程（≈1.3′，同济补充）
- 形如 y′ + P(x)y = Q(x)yⁿ（n ≠ 0, 1）。令 z = y^(1−n)，变成关于 z 的一阶线性方程。
- Mistral 骑士“变身”。
- 例：y′ + y = y²（n = 2）⇒ z = 1/y，z′ − z = −1 ⇒ z = 1 + Ceˣ ⇒ y = 1/(1 + Ceˣ)。
- 回看 P6：logistic dP/dt = kP − (k/M)P² 就是 n = 2 的伯努利方程，换元后得到同一个 S 形公式。
- 随堂一题：y′ + y = y³，该令 z 等于什么？答：z = y⁻²。

### P12｜可降阶的高阶方程（≈1.5′，同济补充）
- 三种类型：
  1. y″ = f(x)：连续积分两次。随堂改编：y″ = 6x，y(0) = 0，y′(0) = 0 ⇒ y = x³。
  2. y″ = f(x, y′)（不含 y）：令 p = y′。同济例：(1 + x²)y″ = 2xy′，y(0) = 1，y′(0) = 3 ⇒ p = 3(1 + x²) ⇒ y = x³ + 3x + 1。
  3. y″ = f(y, y′)（不含 x）：令 p = y′，y″ = p dp/dy。
- Kimi：“把 y′ 记成新的未知函数 p，二阶就降成一阶。”
- 陷阱：每积一次多一个常数，及时用初始条件定常数。
- 随堂一题：y″ = 0 的通解？答：y = C₁x + C₂。

### P13｜二阶常系数齐次方程（≈1.5′，同济补充）
- y″ + py′ + qy = 0。猜 y = e^(rx)，代入得特征方程 r² + pr + q = 0。
- 解的结构：两个线性无关的解 y₁、y₂，通解 C₁y₁ + C₂y₂（叠加原理）。
- GLM 整理成表：
  - 两个不等实根：y = C₁e^(r₁x) + C₂e^(r₂x)。例 y″ − 5y′ + 6y = 0 ⇒ r = 2, 3。
  - 重根：y = (C₁ + C₂x)e^(rx)。同济例：y″ + 2y′ + y = 0，y(0) = 4，y′(0) = −2 ⇒ y = (4 + 2x)e^(−x)。
  - 共轭复根 α ± βi：y = e^(αx)(C₁cos βx + C₂sin βx)。例 y″ − 2y′ + 5y = 0 ⇒ r = 1 ± 2i。
- 随堂一题：y″ + 4y = 0 的通解？答：C₁cos 2x + C₂sin 2x。

### P14｜待定系数法（≈1.5′，同济补充）
- 非齐次 y″ + py′ + qy = f(x)：通解 = 齐次通解 + 一个特解 y*。
- Gemini：“猜一个和 f 长得像的！”多项式猜多项式，e^(λx) 猜 e^(λx)。
- 同济例 1：y″ − 2y′ − 3y = 3x + 1 ⇒ 猜 y* = ax + b ⇒ y* = −x + 1/3。
- 同济例 2：y″ − 5y′ + 6y = xe^(2x)，2 是特征根 ⇒ 要多乘一个 x：y* = x(ax + b)e^(2x) ⇒ y* = −(x²/2 + x)e^(2x)。
- 陷阱：λ 是特征根时不乘 x 会解不出来（代进去全消掉）。单根乘 x，重根乘 x²。
- 随堂一题：y″ + y = eˣ 的一个特解？答：y* = eˣ/2。

### P15｜弹簧振动（≈1.5′，Stewart 17.3）
- 第 6 章胡克定律 F = −kx，加上牛顿第二定律：mx″ + cx′ + kx = 0（c 是阻尼）。
- Stewart 17.3 例 1：m = 2 kg，k = 128 N/m，拉开 0.2 m 放手 ⇒ x = 0.2 cos 8t（简谐振动，周期 π/4 秒）。
- 加阻尼（例 2 思路）：c = 40 ⇒ r² + 20r + 64 = 0 ⇒ r = −4, −16，过阻尼。x(0) = 0、x′(0) = 0.6 ⇒ x = 0.05(e^(−4t) − e^(−16t))。
- Grok 核实三种情况：c² − 4mk > 0 过阻尼（慢慢回位）、= 0 临界阻尼（最快回位，汽车减震器）、< 0 欠阻尼（越摆越小）。
- 强迫振动与共振：外力频率等于固有频率时振幅越来越大（P14 的“乘 x”在物理上就是共振）。
- 随堂一题：m = 1，k = 4，c = 4，属于哪种？答：c² − 4mk = 0，临界阻尼。
