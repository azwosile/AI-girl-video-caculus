## 0. 设计原则

| 原则 | 做法 |
|---|---|
| **一条主线：积分就是“加权求和”** | 第 6 章用积分算面积、体积、功。本章把同一个想法用到更多“总量”和“平均”上：平衡点 = 质量加权的平均位置；消费者剩余 = 每一杯省下的钱加起来；血流 = 每一圈的流速乘面积加起来；期望等待时间 = 时间按概率加权求和。 |
| **开场的问题最后解决** | P0 提出“平均等 5 分钟，第一分钟就排到的概率是多少？”，代数答不了。P11 学会概率密度，P12 用指数分布给出答案：约 18%；超过 5 分钟约 37%；中位数只有约 3.5 分钟。 |
| **每个公式都先切微元** | 沿用第 6 章 P8 的微元法：先切一小块，写出这一小块的贡献，再积分。画面统一用高亮的一小条或一小圈表示微元。 |
| **呼应前几章** | 第 6 章弧长、侧面积、压力 → P1 速通；第 7 章辛普森法则 → P2 算弧长比赛；第 7 章分部积分 → P12 指数分布的均值；第 7 章 ∫e^(−x²) 和高斯积分 √π/2 → P13 正态分布；第 6 章 P0 祖暅原理的“切片” → P7 帕普斯定理。 |

## 3. 分段详案（草案）

### P0｜服务器繁忙，请稍后再试（≈1.5′）
- 屏幕弹出“服务器繁忙，请稍后再试”，排队的人越来越多。大肥鱼：“本鲸……真的很忙。”
- 千问悄悄接单：“忙不过来就外包给我嘛～”
- Claude 提问：平均等 5 分钟。第一分钟内就排到的概率是多少？等超过 5 分钟的概率呢？
- 大肥鱼：“平均 5 分钟，那第一分钟就是五分之一？”GPT：不对，等待时间不是均匀分布的。
- Claude：要回答，得把“概率”看成曲线下的面积。本章用积分算各种“总量”和“平均”：平衡点、省下的钱、血流、等待时间。答案留到 P12。
- 随堂一题：曲线下面积等于概率，那整条曲线下的面积应该是多少？答：1。

### P1｜速通：弧长、侧面积与压力（≈1.2′）
- Kimi 背出第 6 章的三个公式：弧长 L = ∫√(1 + f′²) dx；侧面积 S = ∫2πf√(1 + f′²) dx；液体压力 F = ∫ρg·h(y)·w(y) dy。
- Claude：三个公式都是同一个微元法，切一小段 ds，或一小条 dA。
- GPT 补充：弧长积分经常算不出初等原函数（√(1 + 4x²)、√(1 + cos²x)），只能数值计算，P2 用辛普森法则。
- 随堂一题：y = x 从 0 到 1 的弧长？答：√2（∫√2 dx）。

### P2｜弧长函数与弧长比赛（≈1.5′）
- 弧长函数 s(x) = ∫ₐˣ√(1 + f′(t)²) dt，ds/dx = √(1 + f′²)。
- Stewart 8.1 例 4：y = x² − ⅛ln x，从 1 开始量。1 + f′² 正好是完全平方 (2x + 1/(8x))²，所以 s(x) = x² + ⅛ln x − 1。
- Grok 主持弧长比赛：曲线过 (0, 0) 和 (1, 0)，在 [0, 1] 上和 x 轴围成的面积都是 1，谁最短？
  - 三角形（高 2）：√17 ≈ 4.123；
  - 正弦 (π/2)sin πx：≈ 3.366（辛普森）；
  - 抛物线 6x(1 − x)：≈ 3.249。
  - Grok：“这是真的吗？”逐条核实。抛物线最短，尖角最费长度。
- 随堂一题：s(x) = x² + ⅛ln x − 1，从 1 量到 2 的弧长？答：3 + ⅛ln 2 ≈ 3.087。

### P3｜参数方程的弧长：摆线（≈1.5′）
- 曲线写成 x = x(t)、y = y(t)：ds = √(x′² + y′²) dt。先用圆检验：x = r cos t、y = r sin t → 2πr。
- Mistral 的车轮滚一圈：x = a(t − sin t)、y = a(1 − cos t)。
- √(x′² + y′²) = a√(2 − 2cos t) = 2a·sin(t/2)，一拱的弧长 = ∫₀^{2π} 2a sin(t/2) dt = 8a。
- Mistral：“车轮周长 2πa ≈ 6.28a，轮缘上一点却走了 8a！”
- 随堂一题：x = t²、y = t³ 从 t = 0 到 1 的弧长？（用 ∫t√(4 + 9t²) dt）答：(13√13 − 8)/27 ≈ 1.44。

### P4｜极坐标下的面积（≈1.5′）
- 极坐标 r = f(θ)：微元不是长条，而是一小片扇形，面积 ½r² dθ。A = ½∫r² dθ。
- 先检验：r = a 的圆 → ½a²·2π = πa²。
- 豆包画心形线 r = a(1 + cos θ) 送家人们：A = ½∫₀^{2π} a²(1 + cos θ)² dθ = 3πa²/2（用第 7 章降幂公式）。
- 陷阱：r = cos 2θ 的四叶玫瑰，θ 只要转 0 到 π/2 的一片，再乘 4……积分区间要看图。
- 随堂一题：r = 2cos θ 围成的面积？答：π（它是圆心 (1, 0)、半径 1 的圆）。

### P5｜矩与质心：跷跷板（≈1.5′）
- 跷跷板：大肥鱼 m₁ 坐在左边，千问 m₂ 坐在右边。平衡条件 m₁d₁ = m₂d₂（阿基米德杠杆原理）。
- 数轴上的多个质点：矩 M = Σmᵢxᵢ，质心 x̄ = M / m = Σmᵢxᵢ / Σmᵢ。质心是“按质量加权的平均位置”。
- 平面上的质点：Mᵧ = Σmᵢxᵢ，Mₓ = Σmᵢyᵢ，(x̄, ȳ) = (Mᵧ/m, Mₓ/m)。
- Llama 慢慢移动支点，找到平衡点。
- 随堂一题：质量 2 在 x = 1、质量 3 在 x = 6，质心在哪？答：x̄ = (2 + 18)/5 = 4。

### P6｜平面薄片的形心（≈1.5′）
- 均匀薄片（密度 ρ）：切竖条，竖条的质心在中点 (x, ½f(x))。
- x̄ = (1/A)∫x f(x) dx，ȳ = (1/A)∫½f(x)² dx；密度消掉，只和形状有关，叫形心。
- Stewart 例 4：半径 r 的半圆，ȳ = 4r/(3π) ≈ 0.42r。
- Stewart 例 5：y = x 和 y = x² 围成的区域，A = 1/6，形心 (1/2, 2/5)。
- GLM 把书顶在指尖上：形心就是指尖要顶的地方。陷阱：形心不一定在图形里面（月牙、圆环）。
- 随堂一题：0 ≤ y ≤ x、0 ≤ x ≤ 1 的三角形，x̄ 是多少？答：2/3。

### P7｜帕普斯定理（≈1.2′）
- 帕普斯定理：平面区域 R 绕一条不穿过它的直线旋转，体积 V = A·2πd，d 是形心到轴的距离。
- MiniMax 拍甜甜圈：半径 r 的圆盘，圆心离轴 R，转一圈得到环面，V = πr²·2πR = 2π²Rr²。
- 对比第 6 章：柱壳法要积分，帕普斯一行写完。呼应祖暅原理：都是“切片”与“面积”的组合。
- 反过来用：半圆绕直径转一圈得到球，(4/3)πr³ = (πr²/2)·2πȳ → ȳ = 4r/(3π)，和 P6 一致。
- 随堂一题：边长 1 的正方形，中心离轴 3，绕轴转一圈，体积？答：1 × 2π × 3 = 6π。

### P8｜引力与转动惯量（≈1.5′）
- Grok 坐火箭：万有引力 F = Gm₁m₂/r²，但一根细杆上每一点离得不一样远，要切微元。
- 同济例：长 l、质量 M 的均匀细杆，近端离质点 m 为 a：dF = Gm(M/l)dx / x²，F = GmM / (a(a + l))。当 l → 0 退化回点质量公式。
- 转动惯量 I = Σmr²：细杆绕一端 I = ∫₀ˡ (M/l)x² dx = Ml²/3；绕中点 = Ml²/12。
- Grok：“同一根杆，抓中间转比抓一端转省力四倍！”
- 随堂一题：杆长 2、质量 3，绕一端的转动惯量？答：3 × 4 / 3 = 4。

### P9｜消费者剩余（≈1.5′）
- 千问请奶茶：需求曲线 p = 30 − x/50（第 x 杯顾客愿意付的价格），卖价 18 元，卖出 600 杯。
- 每位顾客省下 p(x) − 18 元，加起来就是消费者剩余 = ∫₀⁶⁰⁰ (p(x) − 18) dx = 3600 元：需求曲线和价格线之间的面积。
- GPT 补充 Stewart 例 1：p(x) = 1200 − 0.2x − 0.0001x²，销量 500 时价格 1075，消费者剩余 ≈ 33333.33。
- 千问：“再买就是了～”大肥鱼：“那本鲸省了多少？”
- 随堂一题：p = 10 − x，卖价 4，消费者剩余？答：6 × 6 / 2 = 18。

### P10｜血流与心输出量（≈1.5′）
- MiMo 跑完步心跳加快。血管里不同半径处流速不同：v(r) = P(R² − r²)/(4ηl)，中间快、管壁处为 0。
- 切同心圆环微元：dF = v(r)·2πr dr，F = πPR⁴/(8ηl)（泊肃叶定律）。
- 关键：流量和 R⁴ 成正比，血管半径变成一半，流量只剩 1/16。
- 心输出量（染料稀释法）：注入 A mg 染料，测浓度 c(t)，F = A / ∫c(t) dt。Stewart 例 2：c(t) = ¼t(10 − t)，A = 5，∫₀¹⁰ c dt = 125/3，F = 0.12 L/s = 7.2 L/min。
- 随堂一题：半径变为原来的 2 倍，流量变为几倍？答：16 倍。

### P11｜概率密度函数（≈1.5′）
- 连续随机变量 X 的概率密度 f：f ≥ 0，∫f = 1，P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx。单点概率是 0。
- 混元按计算器：Stewart 例 1，f(x) = 0.006x(10 − x)，0 ≤ x ≤ 10。验证 ∫₀¹⁰ f = 1；P(4 ≤ X ≤ 8) = 0.544。
- 陷阱：f(x) 的值不是概率，可以大于 1；只有面积才是概率。
- 随堂一题：f(x) = c 在 [0, 4] 上（其余为 0），c 是多少？答：1/4。

### P12｜均值、中位数与指数分布（≈1.5′）
- 均值 μ = ∫x f(x) dx（按概率加权的平均）；中位数 m：∫_{−∞}^m f = ½。
- Gemini 搜到：排队等待时间常用指数分布 f(t) = (1/μ)e^(−t/μ)，t ≥ 0。用第 7 章分部积分验证均值确实是 μ。
- 回到 P0：μ = 5 分钟。
  - 第一分钟内排到：P(T ≤ 1) = 1 − e^(−1/5) ≈ 0.181（不是 1/5）；
  - 等超过 5 分钟：P(T > 5) = e^(−1) ≈ 0.368；
  - 中位数 = 5 ln 2 ≈ 3.47 分钟：一半的人不到 3.5 分钟就排到，平均值被少数等很久的人拉高了。
- 大肥鱼：“所以本鲸的服务器……一半人 3 分半就能用上！”
- 随堂一题：平均等 10 分钟，等超过 10 分钟的概率？答：e^(−1) ≈ 0.37（和均值无关）。

### P13｜正态分布（≈1.5′）
- f(x) = (1/(σ√(2π)))e^(−(x − μ)²/(2σ²))：钟形曲线，μ 决定中心，σ 决定胖瘦。
- Kimi：为什么前面有 1/(σ√(2π))？因为第 7 章的高斯积分 ∫e^(−x²) dx = √π，保证总面积等于 1。
- e^(−x²) 没有初等原函数，概率只能查表或数值积分（呼应第 7 章 P11–P13）。
- Stewart 例：智商 μ = 100、σ = 15。85 到 115 之间约 68%；高于 130 约 2.3%；高于 140 约 0.38%。
- 68–95–99.7 法则：±1σ、±2σ、±3σ。
- 随堂一题：μ = 100、σ = 15，低于 100 的比例？答：50%（对称）。

### P14｜收束：奶茶小测（≈1.2′）
- 全章地图：中心“∫ 切一小块 → 加起来”，周围 8 个应用（弧长·摆线、极坐标面积、质心·形心、帕普斯、引力·惯量、消费者剩余、血流、概率分布）。GPT：质心 x̄ 与均值 μ 是同一个加权积分。
