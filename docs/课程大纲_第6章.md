## 3. 分段详案（草案）

### P0｜祖暅原理（≈1.5′）
- 千问把两摞同样的金币一摞码正、一摞推斜：“哪摞金子多？”大肥鱼：“当然一样，硬币又没变。”
- Claude：每个高度上的截面都一样大，体积就一样，这就是祖暅原理（公元 5 世纪，比卡瓦列里早约一千一百年）。
- 用它算球：半球与“圆柱挖掉一个倒圆锥”在高度 h 处的截面积都是 π(r² − h²)，所以半球体积 = πr³ − πr³/3 = 2πr³/3，球 = 4/3 πr³。
- 结尾：知道每层截面积 A(x)，就能求体积，这一章就是把这个想法写成积分。
- 随堂一题：两个高相同、底面积相同的立体（一个正棱锥、一个斜圆锥），体积关系？答：相等。
- **动画**：A245 两摞硬币对比（斜推）· A246 半球与挖锥圆柱逐层截面对照 · A247 本章地图（面积 → 体积 → 弧长、侧面积 → 功、压力）

### P1｜高中速通：体积公式（≈1.2′）
- Kimi 背公式：柱 Sh、锥 Sh/3、台 h(S + √(SS′) + S′)/3、球 4/3 πR³、球面积 4πR²。
- Claude：锥体的 1/3 从哪来？截面积 A(x) = S(x/h)²，积分 ∫₀ʰ S x²/h² dx = Sh/3（预告 P4）。
- 随堂一题：底面半径 3、高 4 的圆锥体积？答：12π。
- **动画**：A248 公式卡片墙 · A249 锥体切成薄片、截面面积随 x² 增长 · A250 三个锥拼成一个三棱柱

### P2｜曲线间的面积（≈1.5′，Stewart 6.1 例 1、例 2）
- 公式 A = ∫ₐᵇ [f(x) − g(x)] dx，典型长条高 y_T − y_B。
- 例 1：y = eˣ 与 y = x 在 [0, 1] 之间：e − 1.5。
- 例 2：抛物线 y = x² 与 y = 2x − x² 围成：先求交点 0、1，面积 1/3。
- 豆包把上下弄反，算出 −1/3，笑着道歉。Claude：先画图，认清谁在上面。
- 交错时用 |f − g|：sin x 与 cos x 在 [0, π/2] 上，面积 2√2 − 2。
- 随堂一题：y = x 与 y = x² 围成的面积？答：1/6。
- **动画**：A251 两条曲线之间的长条扫过 · A252 上下交错，各段分别相减 · A253 豆包算出负面积的翻车演示

### P3｜换个方向：对 y 积分（≈1.5′，Stewart 6.1 例 6）
- 区域由 y = x − 1 和 y² = 2x + 6 围成。竖着切，左边的下边界会变，要拆成两块。
- Grok：“横过来切！”x_R = y + 1，x_L = y²/2 − 3，y 从 −2 到 4，A = ∫ (x_R − x_L) dy = 18。
- 随堂一题：y = √x、y = 0、x = 4 围成的区域，对 y 积分怎么写？答：∫₀² (4 − y²) dy = 16/3。
- **动画**：A254 竖切要分两块 · A255 横切一块搞定 · A256 左右边界 x_L、x_R 用颜色标注

### P4｜切片法求体积（≈1.5′，Stewart 6.2 定义、例 1、例 7）
- V = ∫ₐᵇ A(x) dx。MiniMax 像 CT 扫描一样，逐层给出截面。
- 球：A(x) = π(r² − x²)，积分得 4/3 πr³；圆盘近似 n = 5、10、20 时 V ≈ 4.2726、4.2097、4.1940。
- 非旋转体：正四棱锥（底边 L、高 h），A(x) = L²x²/h²，V = L²h/3，接上 P1 的 1/3。
- 随堂一题：截面都是边长 x 的正方形，x 从 0 到 3，体积？答：9。
- **动画**：A257 CT 逐层扫描 · A258 球的圆盘近似（三档 n 的数值表）· A259 四棱锥的截面随 x 放大

### P5｜圆盘法（≈1.5′，Stewart 6.2 例 2、例 3）
- 绕 x 轴旋转，截面是圆盘，A = π(半径)²。
- 例 2：y = √x 在 [0, 1] 下的区域绕 x 轴转，V = π/2。检查：外接圆柱体积 π，答案是它的一半，合理。
- 例 3：y = x³、y = 8、x = 0 围成的区域绕 y 轴转：对 y 积分，x = ∛y，V = 96π/5。
- Gemini：“像陀螺一样转起来！”
- 随堂一题：y = x 在 [0, 1] 下绕 x 轴转，体积？答：π/3（圆锥）。
- **动画**：A260 平面区域转成立体（伪 3D 旋转）· A261 一片圆盘的半径就是函数值 · A262 外接圆柱估算检查

### P6｜垫圈法（≈1.5′，Stewart 6.2 例 4、例 5）
- 区域中间离轴有空隙，截面是垫圈：A = π(R外² − r内²)。混元：铜钱外圆内方，算铜量就是外面减里面。
- 例 4：y = x 与 y = x² 围成的区域绕 x 轴转：A = π(x² − x⁴)，V = 2π/15。
- 例 5：同一区域绕 y = 2 转：外半径 2 − x²、内半径 2 − x，V = 8π/15。
- 陷阱：π(R − r)² ≠ π(R² − r²)。
- 随堂一题：绕 y = 2 转时，外半径是 2 − x 还是 2 − x²？答：2 − x²（离轴更远的是下面那条曲线）。
- **动画**：A263 垫圈截面（环形）· A264 换转轴后内外半径重新量 · A265 错误公式与正确公式的面积对比

### P7｜柱壳法（≈1.5′，Stewart 6.3 例 1）
- 难题：y = 2x² − x³ 与 y = 0 围成的区域绕 y 轴转。横切要解三次方程求内外半径。
- Llama：像树的年轮，一圈一圈。一层壳展开成薄板：周长 2πx × 高 f(x) × 厚 dx。
- V = ∫ 2πx f(x) dx = 2π∫₀² (2x³ − x⁴) dx = 16π/5。
- 随堂一题：y = x、x 从 0 到 1 下的区域绕 y 轴转，柱壳积分？答：∫₀¹ 2πx·x dx = 2π/3。
- **动画**：A266 横切卡在三次方程 · A267 一层壳剥下来压平成长方形薄板 · A268 壳层逐层叠成立体

### P8｜微元法：怎么选（≈1.5′，Stewart 6.3 例 4 + 同济 6.1）
- GLM 捧同济：元素法三步：取 [x, x + dx] → 写出微元 dU ≈ f(x)dx → 积分。前面各段都是这一个套路。
- 例：y = x − x² 与 y = 0 围成的区域绕 x = 2 转：柱壳半径 2 − x、高 x − x²，V = π/2。
- 选法口诀：垂直于转轴切 → 圆盘、垫圈；平行于转轴切 → 柱壳。哪种的积分变量、边界更简单就用哪种。
- 随堂一题：P7 那道题若要横切，需要做什么？答：把 y = 2x² − x³ 解成 x = g(y)，很难。
- **动画**：A269 元素法三步卡片 · A270 绕 x = 2 的壳 · A271 微元对照表（面积、体积、壳）

### P9｜弧长（≈1.5′，同济 6.2 / Stewart 8.1）
- Mistral 丈量弯曲的马道：用折线逼近，每小段长 √(Δx² + Δy²)。
- L = ∫ₐᵇ √(1 + [f′(x)]²) dx。
- 例：y = x^(3/2) 在 [0, 4] 上，L = (8/27)(10√10 − 1) ≈ 9.07；折线 n = 2、4、8 逐步逼近。
- 参数式：L = ∫ √(x′² + y′²) dt，验圆周长 2πr。
- 随堂一题：y = 2x + 1 在 [0, 3] 上的弧长？答：3√5。
- **动画**：A272 折线逼近曲线（n 逐步加倍）· A273 弧长微元三角形 ds² = dx² + dy² · A274 圆周长参数积分

### P10｜旋转体侧面积与加百列号角（≈1.5′，同济 / Stewart 8.2）
- 侧面积 S = ∫ 2πf(x)√(1 + f′²) dx（一圈周长 × 斜边长 ds）。
- 验算球面积：f(x) = √(r² − x²)，得 4πr²。
- 加百列号角：y = 1/x，x ≥ 1，绕 x 轴转。体积 π∫₁^∞ 1/x² dx = π（有限）；侧面积 ≥ 2π∫₁^∞ 1/x dx = ∞。
- 豆包：“体积有限，表面积肯定也有限吧家人们”，被打脸。“装得满油漆，却刷不完外壁。”接第 5 章 P15 的 p 积分。
- 随堂一题：半径 2 的球面积？答：16π。
- **动画**：A275 一圈圆台带展开（周长 × 斜高）· A276 号角无限延伸，体积数字收敛、面积数字发散 · A277 油漆悖论小剧场

### P11｜变力做功与弹簧（≈1.5′，Stewart 6.4 例 2、例 3）
- 恒力 W = Fd（例 1：举起 1.2 kg 的书 0.7 m，W ≈ 8.2 J）。变力：W = ∫ₐᵇ f(x) dx。
- 例 2：f(x) = x² + 2x，从 1 到 3，W = 50/3 J。
- 胡克定律 f(x) = kx。例 3：40 N 能把弹簧从 10 cm 拉到 15 cm，求从 15 cm 拉到 18 cm 做的功：k = 800，W = 1.56 J。
- MiMo 踩弹簧：越压越费劲。
- 陷阱：x 是伸长量，不是弹簧长度；单位要换成米。
- 随堂一题：k = 100 N/m，从自然长度拉长 0.2 m，做功？答：2 J。
- **动画**：A278 力-位移图下的面积就是功 · A279 弹簧伸长与力表 · A280 MiMo 踩弹簧

### P12｜拉缆绳与抽水（≈1.5′，Stewart 6.4 例 4、例 5）
- 例 4（换成公制）：长 100 m、每米 2 N 的缆绳挂在楼顶，全部拉上去：W = ∫₀¹⁰⁰ 2x dx = 10000 J。
- 例 5：倒圆锥水箱（高 10 m、顶半径 4 m）装水到 8 m 深，全部抽到顶部：一层水半径 r = (2/5)(10 − x)，W = ∫₂¹⁰ 1568πx(10 − x)² dx ≈ 3.4 × 10⁶ J。
- 大肥鱼要换鱼缸的水，Kimi 记住每层要抬多高。
- 随堂一题：缆绳题里，上半截缆绳做的功占多少？答：∫₀⁵⁰ 2x dx = 2500 J，只占 1/4。
- **动画**：A281 缆绳分段上升 · A282 水箱分层，每层标出上升距离 · A283 每层功的柱状图

### P13｜液体的压力（≈1.5′，同济 6.3 / Stewart 8.3）
- 压强 p = ρgh 随深度增加。竖直平板各深度的压强不同，要切成水平窄条。
- 窄条受力 dF = ρg·h·w(h) dh。
- 例：大坝闸门是矩形，宽 4 m、高 3 m，上沿在水面：F = ∫₀³ 1000·9.8·h·4 dh = 176400 N。
- 例：梯形闸门（宽度随深度变化），只列式。
- MiniMax 拍大坝：越往下，墙越厚。
- 随堂一题：同一闸门再往下沉 1 m，压力变大还是变小？答：变大，每条的 h 都多 1。
- **动画**：A284 压强随深度渐变（颜色）· A285 水平窄条受力箭头 · A286 闸门下沉对比

## 4. 与同济《高等数学》第 7 版的差异（目录级）
