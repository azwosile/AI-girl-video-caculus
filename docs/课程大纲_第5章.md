## 3. 分段详案（草案）

### P0｜阿基米德切抛物线（≈2′）
- **钩子**：大肥鱼问：直边图形的面积都会算，弯的边怎么办？GLM 捧书讲两千两百年前阿基米德的做法：在抛物线弓形里放一个最大的三角形，剩下两块再各放一个三角形，一层层填满。
- 每一层三角形的总面积是上一层的 1/4，所以弓形面积 = 1 + 1/4 + 1/16 + … = 4/3 倍的第一个三角形。
- Claude：这就是“切细、求和、取极限”。本章把这个动作变成一个运算：定积分；再发现它和导数互为逆运算。
- **动画**：A186 抛物线弓形里三角形逐层填入，层数计数器 · A187 面积条 1、1/4、1/16 … 累加逼近 4/3 · A188 本章地图：面积 → 定积分 → 基本定理 → 积分方法 → 反常积分

### P2｜面积问题：上和与下和（≈2′，Stewart 5.1 例 1、例 2）

- 一般定义：A = lim Rₙ = lim Σ f(xᵢ)Δx；左端点、右端点、任意样本点，极限都一样。

### P4｜定积分的定义（≈2′，Stewart 5.2）
- 定义：∫ₐᵇ f(x) dx = lim Σ f(xᵢ*) Δx（黎曼和），积分号、上下限、被积函数、dx 的含义；只要 f 连续，这个极限就存在。
- Mistral：任意样本点、极限都相同才算数——骑士的严谨。
- 符号面积：x 轴上方为正、下方为负；例：∫₀³ (x³ − 6x) dx = −6.75（上方面积减下方面积）。
- 用几何算积分：∫₀¹ √(1 − x²) dx 是四分之一圆，= π/4；∫₀³ (x − 1) dx = 1.5。
- **动画**：A199 黎曼和的样本点在每个小区间里随意跳动，和收敛 · A200 定积分记号各部分标注 · A201 x³ − 6x 的正负面积着色 · A202 四分之一圆
- **随堂**：∫₋₁¹ x dx = ？（0）

### P5｜中点法则与积分性质（≈2′，Stewart 5.2）

### P6｜积分中值定理与平均值（≈1.5′，同济 + Stewart 6.5）
- 混元：一个月流水总账除以天数 = 平均日流水；连续函数的平均值 f_ave = 1/(b − a)·∫ₐᵇ f。
- 积分中值定理：f 在 [a, b] 连续，则存在 c 使 ∫ₐᵇ f = f(c)(b − a)——面积等于一个矩形。
- 例：1 + x² 在 [−1, 2] 上平均值为 2，c = ±1（原书 6.5 例 1、例 2）。和第 4 章拉格朗日中值定理对照：平均变化率 ↔ 平均值。

### P7｜基本定理（一）：面积函数（≈2′，Stewart 5.3）
- 面积函数 g(x) = ∫ₐˣ f(t) dt：右边界往右推，面积跟着变（原书例 1 的图）。
- 大肥鱼：g 长得多快？右边界多推 h，多出一条细长条，面积 ≈ f(x)·h，所以 g′(x) = f(x)。

- 例：d/dx ∫₀ˣ √(1 + t²) dt = √(1 + x²)；菲涅耳函数 S(x) = ∫₀ˣ sin(πt²/2) dt 没有初等原函数，导数照样能写。

### P8｜变限积分求导（≈1.5′，Stewart 5.3 例 4 + 同济）
- MiMo：兔子沿 t 轴跑到 x⁴ 处，上限跑得越快面积长得越快：d/dx ∫₁^{x⁴} sec t dt = sec(x⁴)·4x³（链式法则）。

### P11｜换元法：凑微分（≈2′，Stewart 5.5）
- 链式法则倒过来：∫ f(g(x)) g′(x) dx = ∫ f(u) du。
- Kimi：一眼认出“里面函数的导数”在外面：∫ 2x√(1 + x²) dx，u = 1 + x²，= (2/3)(1 + x²)^{3/2} + C。
- ∫ x³ cos(x⁴ + 2) dx = (1/4) sin(x⁴ + 2) + C；∫ √(2x + 1) dx = (1/3)(2x + 1)^{3/2} + C；∫ tan x dx = −ln|cos x| + C。同济叫“第一类换元法”。

### P12｜定积分换元与对称性（≈1.5′，Stewart 5.5）

### P13｜三角代换（≈1.5′，同济 + Stewart 7.3）

### P14｜分部积分（≈2′，同济 + Stewart 7.1）
