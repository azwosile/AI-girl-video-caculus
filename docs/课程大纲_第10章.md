## 0. 设计原则

| 原则 | 做法 |
|---|---|
| **一条主线：曲线 = 一个点在运动** | y = f(x) 只能画“每个 x 一个 y”的曲线。让点随时间 t 运动，(x(t), y(t)) 就能画出圆、自交的曲线、摆线、字母的轮廓；换成“转角 θ 和距离 r”，就能画玫瑰线、心形线和行星轨道。 |
| **开场的问题最后解决** | P0：放大“得意黑”的一个字，轮廓是一段段光滑曲线，它们是怎么存进字体文件的？P1–P5 学会参数曲线、切线和长度，P6 揭晓：每段是一条三次（或二次）Bézier 曲线，字体文件里只存控制点，再亲手用四个控制点拼出一个笔画。 |
| **先看点怎么动，再算** | 每条参数曲线先播放“小点沿着曲线走”的动画（带 t 的刻度），再求切线、面积、弧长。极坐标曲线先画旋转的射线和 r 的长度，再连成曲线。 |
| **呼应前几章** | 第 4 章参数方程求导 → P3；第 4 章“曲率本章不讲” → P13；第 6 章旋转体 → P5；第 8 章摆线弧长、极坐标面积 → P4、P11；第 8 章旋转曲面面积 → P5；第 9 章弹簧振动（圆周运动的投影）→ P1。 |

## 3. 分段详案（草案）

### P0｜字母里的曲线（≈1.5′）
- 接第 9 章：MiniMax 给视频加字幕，把“曲线”两个字（得意黑）放大 20 倍：边缘依旧光滑，不是像素。字体文件存的是轮廓线。
- 实测字形（`tools/glyph10.py` 用 fontTools 导出）：“曲”38 段轮廓里 36 段是直线、只有 2 段曲线（笑点：“曲”字不弯）；“线”78 段里 53 段是曲线，每段有端点和一个控制点。
- 大肥鱼：“那就写成 y = f(x) 嘛！”Claude：竖线穿过字母 O 交点不止一个；GPT：竖线 x = 240 穿过 S 六次。不是函数图像。
- 让一个点沿 S 的轮廓走，右边同步画出 x(t)、y(t) 两条函数曲线：x = f(t)，y = g(t)，这就是参数方程。MiniMax：“像录屏一样。”
- 本章两件工具：参数方程（P1–P6）、极坐标（P7–P11），最后圆锥曲线与行星轨道（P12–P14）。
- 随堂一题：单位圆能写成一个函数 y = f(x) 吗？答：不能（上下两半各是一个函数）；参数方程一组就够：x = cos t，y = sin t。

### P1｜参数曲线：让点动起来（≈1.5′）
- 定义：x = f(t)，y = g(t)，t 是参数。点 (x(t), y(t)) 随 t 运动，画出的轨迹就是参数曲线；箭头表示方向。
- Stewart 10.1 例 1：x = t² − 2t，y = t + 1。列表描点，消去 t：x = y² − 4y + 3，是一条抛物线（开口向右）。
- Kimi：同一条曲线，不同的“时间表”：x = cos t，y = sin t 和 x = cos 2t，y = sin 2t 都是单位圆，后者转得快一倍。
- 呼应第 9 章：弹簧的 x = cos t 正是圆周运动在横轴上的投影。
- 陷阱：消参后要检查范围。x = sin²t、y = cos²t 消参得 x + y = 1，但只是 0 ≤ x ≤ 1 的一段线段。
- 随堂一题：x = 3cos t，y = 3sin t 画出什么？答：半径为 3 的圆。

### P2｜摆线、星形线、渐开线（≈1.5′）
- Llama 推着轮子慢慢滚：轮缘上一个点画出摆线（Stewart 10.1 例 7）。推导：x = r(θ − sin θ)，y = r(1 − cos θ)。
- 历史：最速降线与等时曲线（只展示动画，不推导）：小球从摆线的不同高度出发，同时到达底部。
- 同济补充：
  - 星形线 x = a cos³t，y = a sin³t：小圆在半径为 a 的大圆里面滚（四个尖点）。消参：x^(2/3) + y^(2/3) = a^(2/3)。
  - 渐开线 x = a(cos t + t sin t)，y = a(sin t − t cos t)：把绕在线轴上的绳子拉直解开，绳端的轨迹（齿轮的齿形）。
- 随堂一题：摆线滚完一圈，点向前走了多远？答：2πr（轮子周长）。

### P3｜参数曲线的切线与凹凸（≈1.5′）
- 回顾第 4 章 P6：dy/dx = (dy/dt)/(dx/dt)。新增：dy/dt = 0（dx/dt ≠ 0）是水平切线；dx/dt = 0（dy/dt ≠ 0）是竖直切线。
- 二阶导数：d²y/dx² = [d/dt(dy/dx)] / (dx/dt)，不是 (d²y/dt²)/(d²x/dt²)。
- Stewart 10.2 例 1：x = t²，y = t³ − 3t。
  - t = ±√3 都到 (3, 0)：曲线自交，两条切线 y = √3(x − 3) 和 y = −√3(x − 3)。
  - Gemini：“一个点两条切线，两条都对，太漂亮了！”
  - 水平切线在 (1, −2)、(1, 2)，竖直切线在 (0, 0)。
  - d²y/dx² = 3(t² + 1)/(4t³)：t > 0 上凹，t < 0 下凹。
- 例 2（摆线）：θ = π/3 处斜率 √3；θ = 2nπ 处（尖点）dy/dx → ±∞，竖直切线。
- 陷阱：二阶导数别直接用 y″(t)/x″(t)。
- 随堂一题：x = t²，y = t³，t = 1 处斜率？答：3/2。

### P4｜参数曲线的面积与弧长（≈1.5′）
- 面积：A = ∫y dx = ∫g(t) f′(t) dt（注意积分上下限跟着换，方向反了要变号）。
- Stewart 10.2 例 3：摆线一拱下的面积 3πr²，正好是滚动圆面积的 3 倍（伽利略猜过，罗贝瓦尔和托里拆利证明）。
- 弧长：L = ∫√((dx/dt)² + (dy/dt)²) dt。快速回顾第 8 章：摆线一拱长 8r。
- 混元按计算器（星形线，同济习题）：面积 3πa²/8；全长 6a（速度 3a|sin t cos t|，先算四分之一再乘 4）。
- 陷阱：星形线速度在尖点为 0，对称性只算第一象限，避免绝对值出错。
- 随堂一题：x = cos t，y = sin t，0 ≤ t ≤ 2π 的弧长？答：2π。

### P5｜旋转曲面面积（≈1.3′）
- 第 8 章的旋转曲面面积 S = ∫2πy ds，换成参数形式：ds = √((dx/dt)² + (dy/dt)²) dt。
- 千问把半圆 x = r cos t，y = r sin t（0 ≤ t ≤ π）绕 x 轴转一圈，变成珍珠：S = 4πr²（Stewart 10.2 例 6）。
- 进阶：摆线一拱绕 x 轴转一圈的曲面面积 64πr²/3（展示结果和动画）。
- 陷阱：y 是“到旋转轴的距离”，绕 y 轴转要换成 x。
- 随堂一题：半径 2 的球面面积？答：16π。

### P6｜Bézier 曲线：字体的秘密（≈1.5′）
- 回到 P0：字体文件只存控制点。三次 Bézier：B(t) = (1 − t)³P₀ + 3t(1 − t)²P₁ + 3t²(1 − t)P₂ + t³P₃，0 ≤ t ≤ 1。
- de Casteljau 作图：在三条控制边上按比例 t 取点，再连、再取，最后一点就是 B(t)。
- 性质：曲线过首尾两点，在 P₀ 处切线指向 P₁（B′(0) = 3(P₁ − P₀)），整条曲线在控制多边形里面。
- 例：P₀(0, 0)，P₁(1, 2)，P₂(3, 2)，P₃(4, 0) ⇒ B(1/2) = (2, 3/2)。
- MiniMax 拖动控制点：笔画立刻变粗变弯；两段相接处控制点共线，接缝就光滑（Stewart 实验课：用 Bézier 曲线画字母）。
- 得意黑是 TrueType 字体，轮廓用的是**二次** Bézier：B(t) = (1 − t)²P₀ + 2t(1 − t)P₁ + t²P₂（每段一个控制点，P0 里看到的“把手”）；设计软件和 OpenType/CFF 字体用三次。大肥鱼拖动“鲸”字一段曲线的控制点，笔画跟着变形。
- 随堂一题：t = 0 时 B(t) 是哪个点？答：P₀。

### P7｜极坐标（≈1.3′）
- Kimi：说月亮的位置，“朝东偏上 30°，38 万公里”比 (x, y) 更自然。极坐标 (r, θ)：r 是到极点的距离，θ 是从极轴转过的角。
- 换算：x = r cos θ，y = r sin θ；r² = x² + y²，tan θ = y/x。
- Stewart 10.3 例 2、例 3：(2, π/3) ⇒ (1, √3)；(1, −1) ⇒ (√2, 7π/4)（或 (√2, −π/4)）。
- 同一个点有无数种写法：θ 加 2π；r 取负数表示朝反方向走（(−r, θ) = (r, θ + π)）。
- 陷阱：tan θ = y/x 求出的 θ 要看点在第几象限。
- 随堂一题：(−2, 0) 在直角坐标里是哪个点？答：(−2, 0)，即 x 轴负半轴上距原点 2。

### P8｜极坐标作图：心形线与玫瑰线（≈1.5′）
- 作图方法：一根射线转起来，r 随 θ 伸缩，射线尖端画出曲线。先在 (θ, r) 直角坐标里画 r = f(θ)，再“卷”成极坐标图。
- r = 2 cos θ：一个圆，(x − 1)² + y² = 1（Stewart 10.3 例 6）。
- 心形线 r = 1 + sin θ（例 7）。
- Mistral 献玫瑰：r = cos 2θ 四片花瓣（例 8）。规律：r = cos nθ，n 为奇数 n 瓣，n 为偶数 2n 瓣。
- 对称性：把 θ 换成 −θ 方程不变 ⇒ 关于极轴对称；把 r 换成 −r 不变 ⇒ 关于极点对称；把 θ 换成 π − θ 不变 ⇒ 关于竖直线 θ = π/2 对称。
- 随堂一题：r = cos 3θ 有几片花瓣？答：3。

### P9｜极坐标曲线的切线（≈1.3′）
- 把 θ 当参数：x = r cos θ，y = r sin θ，于是 dy/dx = (r′sin θ + r cos θ)/(r′cos θ − r sin θ)。
- 混元按步骤代入，Stewart 10.3 例 9 心形线 r = 1 + sin θ：
  - θ = π/3 处斜率 −1。
  - 水平切线：dy/dθ = cos θ(1 + 2sin θ) = 0 ⇒ θ = π/2、7π/6、11π/6。
  - 竖直切线：dx/dθ = (1 + sin θ)(1 − 2sin θ) = 0 ⇒ θ = π/6、5π/6，以及 θ = 3π/2（分子分母都为 0，用极限判断，是尖点处的竖直切线）。
- 特例：曲线过极点（r = 0）时，切线就是射线 θ = θ₀。r = cos 2θ 在极点的切线是 θ = ±π/4。
- 随堂一题：圆 r = 3（常数）的切线和半径什么关系？答：垂直。

### P10｜极坐标曲线族（≈1.3′，Stewart 实验课）
- 豆包：“家人们，这一家子都姓 r = 1 + c sin θ！”拖动参数 c：
  - c = 0：圆；0 < c < 1/2：凸的；1/2 < c < 1：有个凹窝（酒窝形）；c = 1：心形线（尖点）；c > 1：多出一个内环（蜗线）。
- r = sin nθ 一家：n 从 1 到 6 逐个画出，验证 P8 的“奇 n 偶 2n”。
- r = 1 + c sin nθ 换着 c、n 玩（展示几种花样）。

### P11｜极坐标面积、交点与弧长（≈1.5′）
- 快速回顾第 8 章：A = ∫½r² dθ，扇形一片一片扫过去。
- Stewart 10.4 例 1：四叶玫瑰 r = cos 2θ 一片的面积，θ 从 −π/4 到 π/4：π/8。
- 例 2：MiMo 的草地，在圆 r = 3 sin θ 里面、心形线 r = 1 + sin θ 外面：交点 θ = π/6、5π/6，A = ½∫(9sin²θ − (1 + sin θ)²) dθ = π。
- 交点陷阱（例 2、例 3）：解方程只能找到“同一个 θ 同时到达”的交点；极点（原点）两条曲线在不同 θ 经过，解方程找不到。r = cos 2θ 与 r = 1/2 一共 8 个交点，解方程只得 4 个，另外 4 个来自 r = −1/2。结论：先画图再找交点。
- 弧长：L = ∫√(r² + (dr/dθ)²) dθ。例 4：心形线 r = 1 + sin θ 全长 8。
- 随堂一题：圆 r = 2 用面积公式算，A = ？答：½∫₀^{2π} 4 dθ = 4π。

### P12｜圆锥曲线（≈1.5′）
- 用平面去切圆锥：椭圆、抛物线、双曲线（动画）。Gemini 搜索“哪里有椭圆”：行星轨道、斜着看的圆盘、手电筒光斑。
- 抛物线：到焦点和准线距离相等。x² = 4py，焦点 (0, p)，准线 y = −p。例：y = x²/8 ⇒ p = 2，焦点 (0, 2)。
- 椭圆：到两焦点距离之和 = 2a。x²/a² + y²/b² = 1，c² = a² − b²。例：9x² + 16y² = 144 ⇒ a = 4，b = 3，焦点 (±√7, 0)（Stewart 10.5 例 2）。
- 双曲线：距离之差的绝对值 = 2a。c² = a² + b²，渐近线 y = ±(b/a)x。例：9x² − 16y² = 144 ⇒ 焦点 (±5, 0)，渐近线 y = ±(3/4)x（例 4）。
- 陷阱：椭圆是 c² = a² − b²，双曲线是 c² = a² + b²，别弄混。
- 随堂一题：x²/25 + y²/9 = 1 的焦点？答：(±4, 0)。

### P13｜曲率与曲率半径（≈1.5′，同济补充）
- 第 4 章：二阶导数只告诉我们往哪边弯。现在问：弯得有多厉害？曲率 κ = |dα/ds|：走一单位弧长，切线方向转过多少。
- GLM 整理公式表：
  - 显式 y = f(x)：κ = |y″| / (1 + y′²)^(3/2)。
  - 参数形式：κ = |x′y″ − x″y′| / (x′² + y′²)^(3/2)。
  - 圆：κ = 1/R，处处一样弯。曲率半径 ρ = 1/κ，密切圆（曲率圆）贴着曲线。
- 例：y = x² 在原点 κ = 2，曲率半径 1/2；在 x = 1 处 κ = 2√5/25 ≈ 0.179。
- 椭圆 x = a cos t，y = b sin t：长轴端点 κ = a/b²（最弯），短轴端点 κ = b/a²。摆线拱顶的曲率半径 4r。
- 应用（同济例）：工件内表面截线为 y = 0.4x²，砂轮半径最大不能超过最小曲率半径 1.25 单位；铁路弯道要用缓和曲线，让曲率从 0 慢慢变大。
- 陷阱：二阶导数大不等于曲率大，分母里还有 (1 + y′²)^(3/2)。
- 随堂一题：半径 5 的圆，曲率是多少？答：1/5。

### P14｜极坐标圆锥曲线与行星轨道（≈1.5′）
- 统一定义：到焦点 F 的距离 = e × 到准线的距离。e < 1 椭圆，e = 1 抛物线，e > 1 双曲线（e 是离心率）。
- 焦点放在极点：r = ed/(1 ± e cos θ) 或 r = ed/(1 ± e sin θ)（Stewart 10.6 定理 6）。
- 例 1：焦点在原点、准线 y = −6 的抛物线：r = 6/(1 − sin θ)。
- 例 2：r = 10/(3 − 2cos θ) ⇒ 分子分母同除以 3，e = 2/3，椭圆；准线 x = −5；顶点 (10, 0)、(2, π)。
- 例 3：r = 12/(2 + 4sin θ) ⇒ e = 2，双曲线，准线 y = 3。
- 例 4：把 θ 换成 θ − π/4，椭圆绕焦点转 45°。
- Grok 骑火箭绕太阳：行星轨道 r = a(1 − e²)/(1 + e cos θ)，近日点 a(1 − e)，远日点 a(1 + e)。地球 a ≈ 1.496 × 10⁸ km，e ≈ 0.017 ⇒ 近日点约 1.47 × 10⁸ km，远日点约 1.52 × 10⁸ km。“这是真的吗？”画出来几乎是个圆。
- 随堂一题：r = 4/(1 + cos θ) 是什么曲线？答：抛物线（e = 1）。
