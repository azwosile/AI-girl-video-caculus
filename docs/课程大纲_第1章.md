## 1. 高中已学 vs 大学重点

| 主题 | 高中已学（P1 速通） | 大学要讲（展开） |
|---|---|---|
| 函数定义 | 两个非空数集间的对应；定义域、值域 | 映射；**陪域与值域的区别**；单射/满射/双射；函数相等 = 定义域 + 对应法则都相同 |
| 表示法 | 解析式、列表、图像 | 分段函数；**画不出图的函数**；符号函数、取整函数、狄利克雷函数；隐式曲线拆成多个函数 |
| 单调性 | 区间上的增减、判定 | **“在每个区间上递减”≠“在定义域上递减”**；用 ∀x₁<x₂ 严格书写 |
| 奇偶性 | 定义、图像对称 | 任意函数 = 偶部 + 奇部；由此引出 **cosh、sinh** |
| 有界性 | 基本不讲 | **∃M ∀x** 的量词语言；量词顺序一换意思全变；无界的严格证明 |
| 周期性 | 三角函数的周期 | 最小正周期不一定存在（狄利克雷函数）；sin x + sin √2x **不是**周期函数 |
| 复合函数 | 简单代入 | **复合定义域** {x∈D_g : g(x)∈D_f}；把复杂函数拆成复合链（为链式法则铺路）；f∘g ≠ g∘f |
| 反函数 | 同底指数、对数互为反函数 | 存在条件（一一对应）；严格单调 ⇒ 可逆；按三步求反函数；f⁻¹ ≠ 1/f；反双曲函数 |
| 三角函数 | 图像、诱导公式 | **反三角函数**：限制定义域取主值；arcsin(sin x) 的锯齿图；精确值与三角形代换 |
| 指数函数 | 运算法则、图像、“指数爆炸” | **e 的定义**（在 (0,1) 处切线斜率为 1）；增长阶 ln x ≪ xᵃ ≪ aˣ |
| 模型 | 几类函数模型 | 经验建模与拟合；看图窗口的陷阱（Stewart 1.2、1.4） |
| 整体 | — | **初等函数**的定义；函数在一点附近的行为 → 极限预告 |

### P2｜函数的大学定义：映射（10′）
- 映射 f: X → Y；**陪域 Y ≠ 值域 f(X)**；单射、满射、双射（*injective / surjective / bijective*）。
- 同一个法则换定义域或陪域，性质就变：x² 在 ℝ→ℝ 上既不单也不满，在 [0,∞)→[0,∞) 上是双射。
- **函数相等**：f(x) = x 与 g(x) = x²/x 不相等（g 在 0 处没定义）。
- 特殊函数：sgn x、⌊x⌋、|x| = √(x²)、分段函数、狄利克雷函数回顾。
- 竖直线检验是定义的直接推论；圆 x² + y² = 4 可以拆成上、下两个半圆函数。
- **动画**：A09 映射粒子流 · A10 单射/满射/双射三连 · A11 放大找出 x²/x 的洞 · A12 特殊函数“拼图” · A13 圆拆成两个函数
- **随堂**：f(x) = x³ − x，ℝ→ℝ，是单射吗？是满射吗？

### P3｜性质的严格语言（11′，慢，全章难点）
- **量词**：∀、∃ 的含义；“∃M ∀x |f(x)| ≤ M”（有界）与“∀x ∃M |f(x)| ≤ M”（对任何实值函数都成立）只差一个顺序。
- **有界**：1/x 在 (0,1) 上无界（对任意 M 都能找到 x 让 1/x > M）、在 [1,∞) 上有界；sin(1/x) 在 0 附近震荡得很疯，但有界。
- **单调**（10-27 决策：高中已学，只留一句提醒）：讨论增减必须说明区间。原定的 ∀x₁<x₂ 严格书写与 1/x 陷阱不展开；1/x 的“分段递减 ≠ 整体递减”留到 P4 讲可逆性时再提。
- **奇偶**：定义域关于原点对称；任意函数 = 偶部 (f(x)+f(−x))/2 + 奇部 (f(x)−f(−x))/2；eˣ = cosh x + sinh x，并顺带讲**双曲函数**（同济有，Stewart 放在 3.11）。
- **周期**：T 是周期 ⇔ f(x+T) = f(x)；最小正周期不一定存在：狄利克雷函数以任意正有理数为周期；sin x + sin √2x 不是周期函数。
- Gemini 客串：“看起来有界”就下结论，被 x·sin x 打脸。
- **动画**：A14 量词对战 · A15 有界带与逃逸 · ~~A16 单调探针~~（取消）· A17 镜像折叠出奇偶分解 · A18 周期平移对齐 · 另加 √2 两列刻度对不齐、悬链线下垂
- **随堂**：x·sin x 在 ℝ 上有界吗？**常数函数有最小正周期吗？**（10-27 替换原“1/x 在定义域上递减吗？”）x³ + sin x 是奇函数还是偶函数？

### P4｜复合与反函数（原定 10′，10-27 重做后实测 4.0′）
> 10-27：旧版归档到 `ch1/_bak_20261027_p4_old/`，按 P1–P3 标准整段重做；台词 40 句（字幕与朗读稿逐句对应），用户审稿后配音。
- **复合定义域**：f(u) = √u，g(x) = 1 − x²，f∘g 的定义域是 [−1, 1]。
- 把 sin²(3x+1) 拆成复合链（为第 3 章链式法则铺路）；f∘g ≠ g∘f。
- **反函数**：只有一一对应才可逆；严格单调 ⇒ 可逆；按课件三步求反函数；f⁻¹ ≠ 1/f。
- 例：y = sinh x ⇒ arsinh x = ln(x + √(x²+1))，正好接上 P3。
- Kimi 客串：一口气拆一条超长复合链（性格：长文本、耐心）。

### P5｜反三角函数（原定 7′，实测 3.0′）
- 正弦在 ℝ 上不是一一对应 → 限制在 [−π/2, π/2] → arcsin；同理 arccos 用 [0, π]，arctan 用 (−π/2, π/2)，arccot 用 (0, π)（课件 13–15 页）。
- arcsin(sin x) ≠ x，它的图像是锯齿形；sin(arcsin x) = x 只在 [−1,1] 上成立。
- 精确值和三角形代换：sin⁻¹(√3/2) = π/3，arctan 1 = π/4，cos(arcsin x) = √(1−x²)（对应课件 Ex 1.6 第 63、65 题的题型）。
- Grok 客串：说“arcsin(sin 2) 就等于 2，别绕弯子”，被纠正为 π − 2。
- **动画**：A26 剪下正弦再翻折 · A27 单位圆联动 · A28 arcsin(sin x) 锯齿 · A29 三角形代换
- **随堂**（10-27 定稿）：① arctan(−1)（= −π/4）② cos(arcsin 3/5)（= 4/5）。arcsin(sin 2) 已在锯齿段由 Grok 翻车讲过，留到 P7 出口票复用。

### P6｜指数、e 与增长（原定 7′，实测 3.3′）
- 运算法则只用一张回忆卡（高中）。
- **e 的定义**（Stewart 1.5）：在所有 aˣ 中，只有一个底数让曲线在 (0,1) 处的切线斜率恰好为 1，这个底数就是 e ≈ 2.71828。复利 (1 + 1/n)ⁿ 作为第二个视角。

- 经验建模（Stewart 1.2）：同一组数据用直线和指数分别拟合，比较残差；看图窗口陷阱（1.4）。数据是固定种子生成的示例数据，画面标“示例数据”。

### P7｜收束（原定 5′，实测 2.6′）
- **初等函数**：由常数、幂、指数、对数、三角、反三角函数经有限次四则运算与复合得到的函数；狄利克雷函数不在其中。
- **极限预告**：sin x / x 在 0 处没有定义，但 x 越靠近 0，值越接近 1；割线转成切线（Stewart 2.1）。
