## 数学与史实复核

| 说法 | 核对 |
|---|---|
| 有理数、无理数在实数中都稠密 | 成立：任意区间 (a,b) 内两者都有无穷多个 |
| 狄利克雷函数是函数，但无法画出 | 成立：每个 x 只有一个值；图像在 y=0、y=1 两条线上都稠密 |
| 欧拉 1748 年把函数看作解析式 | 《无穷分析引论》（1748）的定义；欧拉 1755 年已放宽，台词只说“那时候” |
| 傅里叶用正弦级数表示有折角的函数 | 1807 年提交的热传导论文；方波的傅里叶级数只含奇次谐波，吉布斯过冲约 9% |
| 狄利克雷 1837 年给出“任意对应”的函数定义 | 通常引用 1837 年论文；狄利克雷函数本身出现于 1829 年，台词不写具体年份 |
| 1 + √2/100000 在 1 与 1.0001 之间且为无理数 | 成立：√2/100000 ≈ 0.0000141；有理数加非零有理数倍的 √2 仍是无理数 |
| 0.1 的双精度存储值 = 3602879701896397 / 2⁵⁵ | 成立：IEEE 754 双精度最接近 0.1 的数，所有有限浮点数都是二进分数 |
