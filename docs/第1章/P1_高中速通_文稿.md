## 数学复核

- C03/C04：√(4−x) 要求 x ≤ 4；分母 x − 1 ≠ 0；ln(x+2) 要求 x > −2。交集 (−2, 1) ∪ (1, 4]，4 取到、−2 和 1 取不到，数轴端点实心/空心与此一致。
- C06：竖线检验是“每个 x 至多一个 y”的图像说法；圆 x² + y² = r² 被竖线交两点，不是 y 关于 x 的函数（P2 会把它拆成上下两个半圆函数）。
- G02：aˣ（a > 0, a ≠ 1）过 (0, 1)，渐近线 y = 0；logₐx 过 (1, 0)，渐近线 x = 0；1/x 两条渐近线为两坐标轴。
- C09–C11：y = a·f(b(x − h)) + k。h > 0 右移，k > 0 上移，|a| > 1 竖向拉伸，|b| > 1 横向压缩，a < 0 关于 x 轴翻折。原图在 x = 0 处的点，新图要等 x − h = 0 即 x = h 才出现，所以右移 h。
- C12：aᵐ·aⁿ = aᵐ⁺ⁿ，(aᵐ)ⁿ = aᵐⁿ（a > 0）。方块图用 m = 3、n = 2 示例。
- C13：log(xy) = log x + log y（x, y > 0）；计算尺按 log₁₀ 刻度，log 2 + log 3 = log 6。
- 随堂：1/√(x−3) 要求 x − 3 > 0，即 x > 3；(x + 2)² 由 x² 左移 2，顶点 (−2, 0)；log₂8 = 3 因为 2³ = 8。
