## 1. 高中已学 vs 大学重点

| 主题 | 高中已学（P1 速通） | 大学要讲（展开） |
|---|---|---|
| 指数函数 | (eˣ)′ = eˣ、(aˣ)′ = aˣ ln a 直接给出 | 用导数定义推出 (aˣ)′ = aˣ · lim (aʰ − 1)/h；**e 是让这个极限等于 1 的底数**；数值找 e（3.1） |
| 三角函数 | (sin x)′ = cos x、(cos x)′ = −sin x 直接给出 | 用和角公式 + 第 2 章的两个极限证明；tan、cot、sec、csc 的导数；导数四步一循环（第 27 阶导数，3.3） |

| 隐函数 | 不讲 | 两边对 x 求导、把 y 当成 x 的函数；圆、笛卡尔叶形线的切线；**反三角函数的导数**（3.5） |

## 3. 分段详案（草案）

### P0｜齿轮链：变化率相乘（≈2′；台词见 `ch3/p0/P0_台词审稿.md`）

- **从齿轮到导数**：转速忽快忽慢时看“每一瞬间的倍数”，也就是导数。回到第 1 章的复合管道 x → g → u → f → y：x 挪一点，u 跟着挪，倍数 g′；u 再挪，y 跟着挪，倍数 f′；总倍数是两个导数相乘——链式法则。
- GPT：莱布尼茨记号里中间那一层“看起来像被约掉”，只是好记，不是真的约分，证明留到 P4。
- **一例**：y = (2x + 1)³ = 外层“立方”∘ 内层“2x + 1”，导数 3(2x + 1)² · 2 = 6(2x + 1)²；混元展开再求导验算。

### P2｜为什么是 e（≈2′，Stewart 3.1）
- 用定义求 (aˣ)′ = aˣ · lim_{h→0}(aʰ − 1)/h：导数等于函数本身乘一个只和底数有关的常数，也就是 aˣ 在 0 处的斜率。
- 底数 2 时这个斜率约 0.69，底数 3 时约 1.10 ⇒ 中间一定有一个底数让斜率正好是 1，它就是 e ≈ 2.718；于是 (eˣ)′ = eˣ（介值定理呼应第 2 章 P5）。
- **Gemini 客串**：“你的问题非常好！答案显然是 2.5！”——代码窗二分法逼近，2.5 偏小，最后停在 2.71828…
- 课件例：f(x) = eˣ − x 的 f′、f″ 图像对比；y = eˣ 上切线平行于 y = 2x 的点（x = ln 2）。
- **动画**：A89 底数滑块：aˣ 在 0 处的切线斜率随 a 连续变化，斜率 = 1 时锁定 · A90 Gemini 二分法代码窗 · A91 eˣ 与它的导数两条曲线重合 · A92 切线平行于 y = 2x 的点
- **随堂**：y = eˣ 在 x = 0 处的切线方程（y = x + 1）

### P3｜三角函数的导数（≈2′，Stewart 3.3）
- 证明 (sin x)′ = cos x：sin(x + h) 用和角公式展开，用到第 2 章 P3 的 sin h / h → 1 和 (cos h − 1)/h → 0。图像验证：sin x 的斜率追踪器画出的正好是 cos x（接第 2 章 A72）。
- (cos x)′ = −sin x；tan x 用商法则得 sec²x；六个三角函数导数表（csc、sec、cot 只列表不推）。
- **MiMo 客串**：导数四步一圈，抱兔子在四格轮盘上跳，跳 27 步：27 = 4 × 6 + 3，落在第 3 格（课件例：cos x 的第 27 阶导数是 sin x）。
- **动画**：A93 和角公式展开 + 两个极限点亮 · A94 斜率追踪器画出 cos · A95 六函数导数表 · A96 四格轮盘跳 27 步
- **随堂**：(sin x)⁽²⁷⁾ = ?（−cos x）

### P4｜链式法则（≈2.5′，Stewart 3.4）
- 定理：y = f(u)、u = g(x) 都可导 ⇒ (f∘g)′(x) = f′(g(x)) · g′(x)。证明思路：Δy = (f′(u) + ε)Δu，Δu → 0 时 ε → 0（课件证明，避开 Δu = 0 的问题）。
- 外层求导、里层不动，再乘里层导数（“剥洋葱”）。课件例：sin(x²) 与 sin²x 的区别；(x³ − 1)¹⁰⁰；多层 sin(cos(tan x))。
- aˣ = e^{x ln a} ⇒ (aˣ)′ = aˣ ln a，兑现 P1 的公式。
- **豆包客串**：“家人们，sin(x²) 求导就是 cos(x²)！”——漏乘 2x，翻车后道歉。
- **动画**：A97 剥洋葱：一层层拆开、每层导数排成一列相乘 · A98 sin(x²) 与 sin²x 的复合管道对照 · A99 多层管道上的齿轮链（接 A81）· A100 证明里的 ε 随 Δx 缩小
- **随堂**：(sin 3x)′ 与 (sin x)³ 的导数各是什么

### P5｜隐函数求导（≈2′，Stewart 3.5）
- 圆 x² + y² = 25：上下半圆分别是函数，但不用拆开；两边对 x 求导，把 y 当作 x 的函数（y² 的导数要乘 y′，这就是链式法则）⇒ y′ = −x/y；(3, 4) 处切线。
- **Mistral 客串**：“我们法国的笛卡尔！”笛卡尔叶形线 x³ + y³ = 6xy，在 (3, 3) 处切线斜率 −1（课件例）。
- 反三角函数的导数：y = arcsin x ⇔ sin y = x，隐函数求导得 1/√(1 − x²)；arctan x 得 1/(1 + x²)（接第 1 章 P5）。
- **动画**：A101 圆上的切线随点滑动，斜率读数 −x/y · A102 y 身上挂着一个隐藏齿轮（y′）· A103 叶形线与切线 · A104 反三角导数从翻折的图像推出
- **随堂**：x² + y² = 25 在 (3, −4) 处的切线斜率（3/4）

### P6｜对数函数与对数求导法（≈2′，Stewart 3.6）
- y = ln x ⇔ eʸ = x，隐函数求导 ⇒ (ln x)′ = 1/x；(logₐx)′ = 1/(x ln a)；(ln\|x\|)′ = 1/x；链式 (ln g(x))′ = g′/g。
- **对数求导法**：乘积、商、根式一起出现时，先取对数把乘除变成加减（课件例）；幂指函数 y = xˣ：ln y = x ln x ⇒ y′ = xˣ(ln x + 1)。
- 一般幂法则 (xⁿ)′ = nxⁿ⁻¹ 对任意实数 n 成立的证明。
- **GLM 客串**：“乘法太贵了，先取个对数，打折成加法——不过求完导记得乘回 y，这笔账可不能赖。”
- **动画**：A105 eʸ = x 翻折成 ln x，切线斜率互为倒数 · A106 对数把乘除变加减的“折扣”动画 · A107 xˣ 图像与最低点 x = 1/e · A108 幂法则 n 滑块连续变化
- **随堂**：(xˣ)′ 在 x = 1 处的值（1）

### P7｜指数增长与衰减（≈1.5′，Stewart 3.8）
- 变化率与大小成正比：dy/dt = ky ⇒ y = y₀eᵏᵗ（k > 0 增长、k < 0 衰减）。
- 课件例：1950 年世界人口 25.6 亿、1960 年 30.4 亿，求相对增长率 k ≈ 1.7%/年，再预测；放射性衰变与半衰期；连续复利 A₀eʳᵗ（接第 1 章 P6）。
- **千问客串**：本金按连续复利滚动，“钱生钱的速度和钱一样多——再买就是了～”
- **动画**：A109 斜率场：每一点的斜率等于高度 · A110 人口曲线拟合两个数据点并外推 · A111 半衰期阶梯
- **随堂**：半衰期 10 年，40 年后剩多少（1/16）

### P8｜相关变化率（≈2′，Stewart 3.9）
- 方法：写出量之间的关系 → 两边对时间 t 求导（链式法则）→ 代入已知的瞬时值。
- 梯子滑落：底端匀速外移，顶端越落越快（动画直观）；课件例：球形气球体积每秒增加 100 cm³，直径 50 cm 时半径增长多快（1/(25π) cm/s）；热气球与测距仪的仰角（课件例，140 ft/min）。
- **MiniMax 客串**：“咔！慢镜头！”同一画面里几个量同时在变，用时间轴把它们连起来。
- **动画**：A112 梯子滑落，两端速度箭头 · A113 气球膨胀，dV/dt 与 dr/dt 的关系 · A114 热气球仰角与高度 · A115 “对 t 求导”把几个量串成一条齿轮链
- **随堂**：正方形边长每秒增加 2 cm，边长 5 cm 时面积增长多快（20 cm²/s）

### P9｜线性化与微分（≈2′，Stewart 3.10）
- 切线就是曲线在一点附近的最佳直线近似：L(x) = f(a) + f′(a)(x − a)。课件例：f(x) = √(x + 3) 在 a = 1 处线性化，近似 √3.98 ≈ 1.995、√4.05 ≈ 2.0125。
- 微分 dy = f′(x)dx 与增量 Δy 的区别（课件例 y = x³ + x² − 2x + 1，x 从 2 到 2.05）；几何上 dy 走切线、Δy 走曲线（接第 2 章 A75 面积矩形）。
- 误差估计：测球半径误差 → 体积误差。
