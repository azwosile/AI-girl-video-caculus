## 3. 分段详案（草案）

### P0｜芝诺悖论：追不上的乌龟（≈3′，Stewart 2.1；台词见 `ch2/p0/P0_台词审稿.md`）
- **客串**：Grok 演阿喀琉斯，大肥鱼演乌龟，Kimi 交代两个悖论出自亚里士多德《物理学》（台词 v2）。
- **钩子一：阿喀琉斯与乌龟**。领先 100 米，阿喀琉斯每秒 10 米、乌龟每秒 1 米：追到乌龟原来的位置要 10 秒，乌龟又爬了 10 米；再追 1 秒，乌龟又爬 1 米……步数无穷多。把时间加起来 10 + 1 + 0.1 + … 越来越接近 100/9 ≈ 11.11 秒；GPT 用“每秒追回 9 米”直接验算。**无穷多步可以只用有限时间**，“越来越接近一个数”就是极限。
- **钩子二：飞矢不动**。一瞬间箭走 0 米、用 0 秒，速度 = 0 ÷ 0；代码窗 `0/0` 输出 `NaN`（呼应第 1 章 P0 的代码窗）。改成算一小段：小球下落 s = 5t²，[1, 1 + h] 上的平均速度 10 + 5h：10.5、10.05、10.005 → 10 米每秒，这才叫瞬时速度。
- **同一件事在图上**：y = x² 上 P(1, 1)，割线 PQ 斜率 3、2.5、2.1、2.01 → 2，割线转成切线 y = 2x − 1（课件 2.1 例题）。
- **收束**：速度和切线都是“分子分母一起趋于 0 的比”，0/0 要看它往哪儿去——这就是本章的极限。
- **动画**：A41 阿喀琉斯追乌龟：步数无穷、时间条收敛到 100/9 · A42 飞矢定格 + `0/0 → NaN` 代码窗，时间窗收缩、平均速度数列逼近 10 · A43 割线转切线（升级第 1 章 A37，带斜率表）

### P2｜极限是什么（≈4′，Stewart 2.2）
- 记号 lim_{x→a} f(x) = L 与直观定义；**不看 a 点本身**：课件 p9 三个函数（a 处无定义、a 处另定义、a 处正常）极限都是 2。
- 单侧极限；定理：极限存在 ⇔ 左右极限都存在且相等（用来证明极限不存在）。
- 极限不存在的三种方式：跳跃（Heaviside）、趋于无穷（1/x²）、振荡（sin(1/x)）；垂直渐近线（课件例 38(a)：x = 0 与 x = 3/2）。
- **Gemini 客串**：Gemini 用计算器打表 sin(π/x)，x = 1、0.1、0.01… 全是 0，自信宣布“你的观察非常敏锐！极限就是 0！”；GPT 换一组 x（2/5、2/9、2/13…）打表全是 1，图像放大是疯狂振荡（Stewart 2.2 例 4）。
- **动画**：A46 双向探针逼近 a，y 读数收敛 · A47 三函数“挖洞 / 补点”对比 · A48 左右探针各停一层（跳跃）· A49 sin(1/x) 无限振荡放大 · A50 打表陷阱代码窗
- **随堂**：lim_{x→0} |x|/x 是否存在？

### P3｜算极限：法则、0/0 与夹逼（≈4.5′，Stewart 2.3、3.3）
- 极限法则（和、差、积、商、幂、根）一张发光公式组；多项式和有理函数可以直接代入。
- **0/0 未定式**三招：因式分解消零因子 (x² − 2x − 3)/(x − 3)；有理化；拆绝对值（课件 Ex 2.3 第 42 题，左右极限不同 ⇒ 不存在）。
- **夹逼定理**：x² sin(1/x) 被 ±x² 夹住。
- **第一个重要极限**：单位圆里三块面积 sin x / 2 ≤ x / 2 ≤ tan x / 2 ⇒ cos x ≤ sin x / x ≤ 1 ⇒ 极限为 1；推论 tan x / x、(1 − cos x)/x²、sin 3x / x、sin(x − 1)/(x² + x − 2)（课件例题）。兑现第 1 章 P7 的“洞”。
- **豆包客串**：“家人们，sin x / x 把 x 约掉，答案就是 sin！”——糊弄式约分当场翻车，引出“函数名不能拆开约”。
- **混元客串**：算盘噼里啪啦打表，x = 0.1、0.01、0.001 时 sin x / x 逼近 1；夹逼时“上界打一遍，下界打一遍”。
- **动画**：A51 法则拼装 · A52 零因子“抵消”（公式片段变形）· A53 夹逼带收紧 · A54 单位圆三面积 · A55 sin x / x 的洞被填上（呼应 A36）
- **随堂**：lim_{x→0} sin 5x / x = ?

### P4｜ε-δ：讨价还价的定义（≈4′，Stewart 2.4）
- 直观定义里的“任意接近”“足够接近”说不清；改成游戏：**GLM 出价 ε**（y 方向的金色带子要多窄），**Claude 还价 δ**（x 方向的青色带子），只要对每个 ε 都能还出 δ，极限就成立。呼应第 1 章 A14 的量词游戏：∀ε ∃δ，顺序不能换。
- 例：lim_{x→2}(4x + 1) = 9，取 δ = ε/4；lim_{x→1}(x² − 1)/(x − 1) = 2（x = 1 处没定义也不影响）。
- 无穷极限的精确定义：用 M 换掉 ε（课件 x → 1 时 1/(x − 1) 一类的例子）。
- **Mistral 客串**：“这个定义是我们法国的柯西先写出来的”，再由魏尔斯特拉斯改成今天的 ε-δ 写法（19 世纪）。
- **动画**：A56 ε 带与 δ 带联动（ε 收窄，δ 跟着收窄）· A57 GLM 出价、Claude 还价的计分板 · A58 失败案例：跳跃函数在 ε 足够小时怎么还价都不行 · A59 M-δ 竖直带
- **随堂**：lim_{x→3}(2x − 1) = 5，ε = 0.1 时 δ 最大能取多少？（0.05）

### P5｜连续与介值定理（≈4′，Stewart 2.5）
- 定义：f 在 c 处连续 ⇔ lim_{x→c} f(x) = f(c)（三个条件：有定义、极限存在、相等）；左连续、右连续。
- 间断点：可去（补一个点就好）、跳跃（⌊x⌋ 在整数处）、无穷、振荡；同济的第一类 / 第二类分法在这里对照一次。
- 连续函数的和差积商、复合仍连续 ⇒ 初等函数在定义域内连续（呼应第 1 章 P7）；极限可以“穿过”连续函数，如 lim ln(sin x / x)。
- **介值定理**：[a, b] 上连续，f(a)、f(b) 异号 ⇒ 中间有根。课件例 f(x) = x³ + x − 1 在 (0, 1) 内有根；代码窗跑二分法，区间每次减半。
- **MiMo 客串**：抱着兔子一跳，落点和起点不连着——跳跃间断；“补一个点”修不好跳跃，只能修可去间断。
- **Gemini 客串**：坚持“现在是 2024 年”；GPT：从 2024 连续走到 2026，介值定理说你一定经过了 2025。

### P6｜无穷远处：渐近线（≈3.5′，Stewart 2.6、4.5）
- lim_{x→∞} f(x) = L，水平渐近线；1/xʳ → 0；eˣ 在 −∞ 处 → 0，arctan x 两端 → ±π/2（呼应第 1 章 P5）。
- 有理函数：分子分母同除最高次，次数比较三种情况；√ 型的符号陷阱（x → −∞ 时 √(x²) = −x）。
- 斜渐近线：次数高 1 时做多项式除法，y = kx + b（课件 4.5）。
- 呼应第 1 章 P6 的增长阶：x¹⁰ / 1.1ˣ → 0。
- **Llama 客串**：羊驼慢悠悠举着 ∞ 标识往右走，镜头跟着飞向无穷远，曲线贴上渐近线；“开源的，随便拿去用”——把次数比较的口诀送给观众。

### P7｜导数：差商的极限（≈2.5′，Stewart 2.7）
- 定义：f′(a) = lim_{h→0} [f(a + h) − f(a)] / h（另一种写法 x → a）；切线方程 y − f(a) = f′(a)(x − a)。
- 导数 = 变化率：速度、成本边际、温度变化率；单位 = y 的单位 / x 的单位。
- 回到 P0：0 米 / 0 秒的答案就是 s′(t₀)。

### P8｜导函数与可导性（≈4′，Stewart 2.8、3.2）
- 导函数 f′(x)：在每一点求导，得到一个新函数；**由 f 的图像画 f′**（斜率追踪器）；记号 f′、dy/dx、Df。
- **可导 ⇒ 连续，反之不成立**：|x| 的尖角（课件例：左右导数 −1 和 1）、x^{2/3} 的尖点、∛x 的竖直切线；不连续一定不可导。
- **Grok 客串**：巨斧一劈，把光滑曲线劈出一个尖角；放大镜下尖角永远放不平，所以那里不可导。
- 高阶导数：位置 → 速度 → 加速度。
- 求导法则（高中已会用）只讲**为什么**：积法则用面积矩形的增量证明；商法则由积法则推出；幂法则 nxⁿ⁻¹ 用二项展开看一眼。课件例：水平切线 x⁴ − 4x 等。
