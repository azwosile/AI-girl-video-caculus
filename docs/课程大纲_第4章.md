## 3. 分段详案（草案）

### P0｜区间测速：平均与瞬时（≈2′）
- **钩子**：Grok 开着火箭车过一段 20 km 的区间测速，用时 10 分钟，平均 120 km/h，限速 100。她说：“我每一秒都盯着表，绝对没超速！这是真的吗？”
- 大肥鱼画出位移–时间曲线：起点到终点的割线斜率 = 平均速度 120；把这条割线平移，总会在某一点和曲线相切——那一刻的瞬时速度正好是 120。
- 这就是**拉格朗日中值定理**的直观内容；本章就是“导数能告诉我们什么”：最高点在哪、曲线怎么弯、极限怎么算、方程怎么解。
- GPT：前提是车速连续变化、不能瞬移——对应定理的条件“连续、可导”，留到 P3 讲。
- **动画**：A121 区间测速龙门架 + 车辆计时 · A122 位移曲线上割线平移成切线，速度表指针同时指到 120 · A123 本章地图：极值、中值、形状、未定式、作图、优化、牛顿法、原函数
- **随堂**：一辆车 2 小时开了 180 km，能不能断定它某一刻的速度正好是 90 km/h？（能，路程连续可导时）

### P1｜高中速通：单调、极值、最值（≈1.5′，快）
- 三关，每关 ≤ 30 秒：① f′ 的正负 ↔ 单调 ② 导数为 0、两侧变号 ↔ 极值 ③ 闭区间最值 = 比较极值和端点值。
- Kimi 把高中套路“求导 → 令导数为 0 → 列表 → 比较”逐行背出来。
- GPT 点破三个高中没讲的“为什么”：最值一定存在吗？导数为 0 为什么是必要条件？f′ > 0 为什么就一定单调？本章逐个补上。

### P2｜极值与最值（≈2′，Stewart 4.1 + 同济补充）
- **最值定理**（同济补充：闭区间上连续函数有界，并且能取到最大值和最小值）：三个反例说明“闭区间”“连续”缺一不可——开区间 (0, 1) 上的 x、有跳跃的函数、1/x。
- 极大值 / 极小值（局部）与最大值 / 最小值（整体）的区别。
- **费马定理**：可导的极值点处导数为 0；反过来不成立（x³ 在 0 处）。临界点 = 驻点 + 不可导点（|x| 在 0 处、x^{2/3} 的尖点）。
- **闭区间法**：Stewart 例 f(x) = x³ − 3x² + 1 在 [−1/2, 4] 上，候选值 f(−1/2) = 1/8、f(0) = 1、f(2) = −3、f(4) = 17 ⇒ 最大 17、最小 −3。GLM 的定价曲线：最高点落在端点上。
- **动画**：A127 最值定理三反例（开区间、断点、无界）逐个打叉 · A128 山峰山谷标注：局部 vs 整体 · A129 临界点探测器扫过曲线，驻点亮绿、尖点亮红 · A130 候选值擂台：端点和临界点一起比大小
- **随堂**：f(x) = x² − 2x 在 [0, 3] 上的最大值（3，在端点 x = 3）

### P3｜罗尔与拉格朗日（≈2′，Stewart 4.2）
- **罗尔定理**：[a, b] 上连续、(a, b) 内可导、f(a) = f(b) ⇒ 存在 c 使 f′(c) = 0。三个条件各给一个反例（断开、尖点、两端不等高）。
- **拉格朗日中值定理**：把罗尔的图“斜过来”——f′(c) = (f(b) − f(a))/(b − a)；证明思路：减去割线后用罗尔。回收 P0 的区间测速。
- Stewart 例：f(x) = x³ − x 在 [0, 2] 上，割线斜率 3 = 3c² − 1 ⇒ c = 2/√3 ≈ 1.155，数值验证。
- 课件练习：若 c₀ + c₁/2 + … + cₙ/(n + 1) = 0，则 c₀ + c₁x + … + cₙxⁿ = 0 在 (0, 1) 内有根（构造原函数后用罗尔）。
- Mistral：罗尔是法国人；拉格朗日生在都灵，在巴黎成名。
- **动画**：A131 罗尔：水平线从两端等高处下落，切到山顶 · A132 三个条件反例逐个失效 · A133 “斜过来”：坐标系旋转，罗尔图变成拉格朗日图 · A134 割线平移扫描，切点处 c 的数值读出
- **随堂**：f(x) = x² 在 [0, 2] 上的中值点 c（1）

### P4｜中值定理的用法：恒等式与不等式（≈1.5′，Stewart 4.2 + 课件）
- **推论**：导数处处为 0 ⇒ 常数；两个函数导数相同 ⇒ 相差一个常数。课件例：arcsin x + arccos x = π/2。
- **证明不等式**：课件例 |arctan b − arctan a| ≤ |b − a|（导数 1/(1 + c²) ≤ 1）；x/(1 + x) < ln(1 + x) < x（x > 0）。课件的提示：式子里出现“两点之差”和“函数值之差”，就想到拉格朗日，再看中间那个导数比 1 大还是小。
- 混元算账：上下两条线把 ln(1 + x) 夹住，数值表逐行验证。
- **动画**：A135 导数为 0 的函数被“压平”成水平线，两条导数相同的曲线上下平移重合 · A136 拉格朗日“三明治”：c 落在 0 和 x 之间，导数值被夹住 · A137 三条曲线 x/(1 + x)、ln(1 + x)、x 的夹逼图 + 数值表
- **随堂**：用中值定理判断 |sin b − sin a| 和 |b − a| 谁大（|sin b − sin a| ≤ |b − a|）

### P5｜单调、凹凸与拐点（≈2′，Stewart 4.3 + 课件）
- **单调性判别**用拉格朗日证明：f(x₂) − f(x₁) = f′(c)(x₂ − x₁)，导数恒正 ⇒ 递增。
- **一阶导数判别法**：课件例 f(x) = x³ − 6x² + 1，f′ = 3x(x − 4) ⇒ 极大 f(0) = 1、极小 f(4) = −31。
- **凹凸性**（课件：上凹“能盛水”、下凹“会洒水”；同济称凹 / 凸，名称要对照）：f″ > 0 上凹、f″ < 0 下凹；**拐点**是凹凸改变的点。
- **二阶导数判别法**：课件例 f(x) = x³ + 3x² − 24x − 20，驻点 −4 和 2，f″(−4) = −18 < 0 ⇒ 极大 60，f″(2) = 18 > 0 ⇒ 极小 −48。课件例 f(x) = 1 − (x − 2)^{2/3}：导数在 2 处不存在，但仍是极大值。
- MiMo 抱着兔子在曲线上跑：上坡、下坡、山顶；碗口朝上朝下。
- **动画**：A138 f、f′、f″ 三层同步的“符号条带” · A139 盛水的碗 / 洒水的碗随曲线弯曲翻转 · A140 拐点处切线从曲线下方穿到上方 · A141 兔子沿曲线跑，脚下的坡度计实时读数
- **随堂**：f(x) = x³ 的拐点（(0, 0)）

### P6｜求导补充：参数方程与莱布尼茨公式（≈1.5′，同济补充）
- **参数方程求导**：x = x(t)、y = y(t) ⇒ dy/dx = y′(t)/x′(t)；例：圆 x = cos t、y = sin t，斜率 −cot t，在 t = π/4 处为 −1；二阶导 d²y/dx² 不是简单的 y″/x″（常见错误）。
- **莱布尼茨公式**：(uv)⁽ⁿ⁾ 的系数正好是二项式系数，和 (a + b)ⁿ 对照；例 (x²eˣ)⁽ⁿ⁾ = eˣ(x² + 2nx + n(n − 1))。
- MiniMax：参数 t 是镜头时间码，x、y 两个演员各走各的，斜率是两人速度之比——这也是下一段柯西中值定理的画面。
- **动画**：A142 时间码滑块驱动点在圆上走，dx/dt、dy/dt 两个速度箭头 · A143 二阶导的“错误示范”被盖章 · A144 杨辉三角与莱布尼茨公式的系数对齐
- **随堂**：x = t²、y = t³，在 t = 1 处的 dy/dx（3/2）

### P7｜柯西中值定理与洛必达法则（≈2′，同济 + Stewart 4.4）
- **翻车**：Gemini 说“0/0 当然等于 1！”——(x² − 1)/(x − 1) → 2、sin 3x / x → 3，0/0 型什么值都可能。
- **柯西中值定理**：参数曲线 (g(t), f(t)) 上，割线斜率等于某点切线斜率 ⇒ (f(b) − f(a))/(g(b) − g(a)) = f′(c)/g′(c)；g(t) = t 时就是拉格朗日。
- **洛必达法则 0/0 型**：由柯西推出（a 处 f、g 都为 0，c 被挤向 a）。例：lim_{x→1} ln x/(x − 1) = 1；课件例 lim_{x→π} sin x/(π − x) = 1；数值表验证。可以连续用多次（课件“多次用法则”）。
- GPT：只有 0/0 和 ∞/∞ 才能用；对 lim (1 + x)/x 硬用会得到错误答案。

- **随堂**：lim_{x→0} sin 2x / x（2）

### P8｜洛必达续：∞/∞ 与增长赛跑（≈1.5′，Stewart 4.4）
- ∞/∞ 型同样适用；Stewart 例 lim eˣ/x² = ∞（用两次）；课件练习 lim_{x→π/2} tan x / tan 3x = 3（先化成 0/0 更好算）。
- **增长赛跑**（课件 Faster, Slower?）：lim ln x / xⁿ = 0、lim xⁿ / eˣ = 0 ⇒ ln x ≪ x^α ≪ eˣ，x → ∞ 时的速度排行；Llama 是 ln x，“慢，但终究会到”。
- **使用条件**：导数之比的极限要存在；反例 lim (x + sin x)/x = 1，但上下求导得 1 + cos x，极限不存在——洛必达失效不等于原极限不存在。

- **随堂**：lim_{x→∞} x/eˣ（0）

### P9｜其他未定式与第二个重要极限（≈2′，Stewart 4.4 + 同济补充）

- **幂指型 1^∞、0⁰、∞⁰**：先取对数。千问的复利：一年利息 100%，分 n 次结算，(1 + 1/n)ⁿ 越来越接近 e，而不是 1。
- **第二个重要极限**（同济补充）：lim (1 + 1/x)ˣ = e，用取对数 + 洛必达证明；变形 lim (1 + x)^{1/x} = e。课件例：0⁰ 型 lim_{x→0⁺} xˣ = 1；1^∞ 型 lim_{x→1} x^{1/(1 − x)} = 1/e、lim_{x→∞} (sin(2/x) + cos(1/x))ˣ = e²；∞⁰ 型 lim_{x→0⁺} (cot x)^{1/ln x} = 1/e。

### P10｜数列极限：ε-N 与单调有界（≈1.5′，同济补充）
- **ε-N 定义**：对任意 ε > 0，存在 N，n > N 时 |aₙ − A| < ε。和第 2 章 ε-δ 对照：δ 换成 N，“足够近”换成“足够靠后”。Mistral 的骑士决斗：你出 ε，我回 N。例：1/n → 0，取 N = ⌈1/ε⌉。
- **单调有界准则**：单调递增、有上界的数列必有极限。用它说明 (1 + 1/n)ⁿ 收敛（递增、不超过 3），极限记作 e，回收 P9。
- 数列极限和函数极限的关系：函数极限存在 ⇒ 沿 n 取值的数列极限也存在。
- **动画**：A156 数列点列与 ε 带，N 之后的点全部落进带里 · A157 骑士决斗：ε 越出越小，N 越回越大 · A158 (1 + 1/n)ⁿ 点列爬升、被上界 3 拦住
- **随堂**：aₙ = 1/n，ε = 0.01 时 N 至少取多少（100）

### P11｜等价无穷小（≈2′，同济补充）
- 无穷小的比较：高阶、同阶、等价。
- **等价无穷小表**（课件 4.4 第 7 页，x → 0）：sin x ~ x、tan x ~ x、arcsin x ~ x、arctan x ~ x、ln(1 + x) ~ x、eˣ − 1 ~ x、aˣ − 1 ~ x ln a、1 − cos x ~ x²/2、ⁿ√(1 + x) − 1 ~ x/n。Kimi 逐行背出，每行配一张局部放大图。
- 课件例：lim_{x→0} (eˣ − sin x − 1)/(arcsin x)² = 1/2（分母先换成 x²，再洛必达）。
- **替换规则**：乘除里的因子可以整体替换；加减里不能随便换。陷阱：(tan x − sin x)/x³，把两项都换成 x 得 0，正确答案是 1/2。
- 和洛必达对照：同一道题两种做法，等价替换更快。

- **随堂**：lim_{x→0} (1 − cos x)/x²（1/2）

### P12｜泰勒公式初步（≈2′，同济第 3 章 §3）
- 线性化（第 3 章 P9）只用了一次项；想更准，就加二次项、三次项……用多项式去贴函数：在 0 处让函数值、一阶导、二阶导……全部对上，系数就是 f⁽ᵏ⁾(0)/k!。
- 四个常用展开：eˣ = 1 + x + x²/2! + x³/3! + …、sin x = x − x³/3! + …、cos x = 1 − x²/2! + …、ln(1 + x) = x − x²/2 + …；带佩亚诺余项 o(xⁿ)。
- 拉格朗日余项 f⁽ⁿ⁺¹⁾(ξ)/(n + 1)! · xⁿ⁺¹：n = 0 时就是拉格朗日中值定理，回收 P3。
