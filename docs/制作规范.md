# 制作规范

> 原则：**沿用 Git 课已验证的管线和节奏规范，换成深空 + 多风格分层的视觉，并补上数学课需要的动画组件。** 不另起炉灶，不回到“PPT 页 + 慢推镜”。

## 1. 技术栈

```
台词源 ──► 朗读稿/字幕稿 ──► GPT-SoVITS 配音 ──► 逐句 ASR 审核 ──► prep（提速/压停顿/测时长）
_gen_script.py   script.json / subtitles.json   tts_gen.py        qa_asr.py          prep.py → durations.json
      ──► 引擎按实测时长排时间轴 ──► 无头 Chrome 逐帧渲染 ──► 混音 ──► loudnorm 成片
           engine.js renderAt(t)        render.py (Playwright)      mix.py     build.sh
```

| 环节 | 工具 | 来源 / 说明 |
|---|---|---|
| 画面 | Canvas 2D，`window.renderAt(t)` 纯函数，任意一帧可单独渲染 | 思路来自 [mg-styles-15](https://github.com/Vincentwei1021/mg-styles-15)（MIT）；代码沿用 Git 课 `ep3/web/engine.js` |
| 渲染 | Python + Playwright 驱动 Chrome → JPEG 管道 → ffmpeg | Git 课 `render.py`（三集一致，可直接复用），`--sheet` 出联系表 |
| 公式 | 现用 `mathText`（Cambria Math 斜体 + `^`/`_` 上下标）+ `glowMath` 光笔揭示；Smiley 缺 ⁵ ₀ ∈ ℚ 等符号，数学一律走 F_MATH。复杂公式再上 TinyTeX + `dvisvgm` → `Path2D` | TinyTeX 在 `E:\AI\TinyTeX`，暂未启用 |
| 数学动画 | **新增**：引擎内数学组件包 `shared/math.js`（见 3.1 节） | 全部 Canvas 绘制，与时间轴同步 |
| Manim | 仅作备用：极复杂的 3D/变换镜头可预渲染透明视频再贴入 | `TOOLS\manim-env`（Manim CE 0.22）；主线不用，避免两套时间轴 |
| 配音 | GPT-SoVITS（`E:\AI\TTS\GPT-SoVITS-v2pro-20261006nvidia50x0`，API 9880） | 三个角色全部本地克隆，见第 4 节 |
| 音效 / BGM | 音效：Git 课 `audio/sfx` + `ch1/audio/sfx_calc.py` 程序合成（含柔和音色组）；BGM：署名授权曲 `ch1/audio/music/bgm.mp3` | 规则见 3.4 节 |
| 混音 | `mix.py`：人声 + 音效 + BGM（RMS 归一 0.12 → ×0.30，遇人声闪避 60%，循环处 2 s 交叉淡化），tanh 软限幅；`build.sh` loudnorm −16 LUFS / 48 kHz | 沿用 |
| 质检 | `qa_asr.py`（Paraformer + 无调拼音比对，<0.85 标 ⚠）+ 联系表 + 响度 | 沿用，另加节奏检查（第 2 节） |
| 立绘 | ZipZipPipe 原设定 → Arena 生图（竖版 9:16、头顶留空、纯绿底）→ `tools/key.py` 抠图白描边 | 沿用；每张数手 |

## 2. 节奏：弹性密度 + 硬上限

不再固定每段 10 分钟。按内容难度分三档，**静音和空白的上限不变**。

| 档位 | 用于 | 密度（汉字/分钟） |
|---|---|---|
| 快 | 高中速通、回忆卡、过渡句 | ≈ 330 |
| 标准 | 一般讲解 | ≈ 290 |
| 慢 | 全章难点（量词、反函数存在性、复合定义域） | ≈ 260 |

| 硬指标（所有档位） | 上限 | 上一版 v0.3 |
|---|---|---|
| 静音占比（无人声时长 / 总长） | **≤ 15%** | 64% |
| 单次无人声 | **≤ 1.5 s**；思考题倒计时 ≤ 3 s，且期间必须有动画 | 40+ s |
| 画面无数学对象变化 | **≤ 2 s** | 整页 60 s |
| 句间间隔 | 同人 0.2 s · 换人 0.25 s · 换段 0.18 s（Git 课 ep3 v2 参数） | — |

- 提速初值：Claude ×1.10、GPT ×1.12、大肥鱼 ×1.08，按样片微调。
- **分段语速（10-27 起）**：默认值写在 `ch1/web/prep.py` 的 `TEMPO`，不要改；某段需要更慢/更快时，在该段目录放 `pN/tempo.json`（如 `{"C": 1.02, "G": 1.04, "M": 1.02}`），只覆盖列出的角色。目前只有 P3（全章难点）用：约 280 字/分。难点放慢靠**删字、加动画**，不靠拉长停顿。
- `BEAT(块, 秒)` 只挂在公式/图像揭示后，实际 ×0.35，单个 ≤ 1 s。
- **新增 `check_pace.py`**：读 `out/timeline.json`，按每段在大纲里标的档位检查密度 ±10% 和上表硬指标；超标就让 `build.sh` 报错，不出片。

## 3. 视觉规范：深空底 + 多风格分层

**结论**：底色从象牙纸改成**深色稀疏星空**。理由：①发光曲线、坐标在深色上对比最好，长时间看不累（3B1B 也用深底）；②白描边贴纸立绘在深底上最突出；③构成主义的红、米白、黑色块放在深底上像海报拼贴，仍然鲜明。构成主义从“全片底色”降为“版式与强调层”，再加两种合适的风格，按图层分工：

| 图层 | 风格 | 负责什么 | 规则 |
|---|---|---|---|
| L0 背景 | **深空星图** | 全片底色 | 深靛渐变 `#0A0F1F → #131B34` + 暗角；星星稀疏（1080p 约 150 颗，三层视差，漂移 2–6 px/s）；只有 10% 的星星轻微闪烁；数学工作区内的星星亮度压到 30% 以下，不抢视线 |
| L1 数学 | **发光矢量**（3B1B 式） | 曲线、坐标、点、箭头、粒子 | 线宽 4–6 px + 轻微外发光；颜色按变量固定（见下）；可见网格只在需要时淡入 |
| L2 版式 | **构成主义（克制）** | 段标题、唯一的印章、进度条 | **不用卡片承载内容**（P0 v2 起）：定义、术语、标签一律写成发光字/发光公式直接放在工作区；构成红只做强调色。整段最多 1 个印章 |
| L3 工程 | **蓝图 / 终端** | 坐标网格、几何作图、代码窗 | 蓝图网格为细青线；代码窗沿用 Git 课终端组件，换成深色半透明玻璃底 |
| L4 角色 | ZipZipPipe 贴纸 | 立绘、探头反应 | 白描边 + 淡淡的轮廓光，站在一块构成主义几何台（红斜块）上 |

> **例外（10-27 决策）**：P2 保留 3 张“小贴士”教材原文卡（取整函数、竖线检验、函数相等），因为它们承载的是教材原文对照，不是讲解内容。要求：不得遮挡当前公式/图像；中文出处写“中文表述（参照同济《高等数学》第七版）”，英文出处写到 Stewart 小节/例题号。其他段不新增卡片。

同一镜头里除背景外**最多叠两层风格**，避免变花。

**颜色语义（全章固定）**

| 对象 | 颜色 |
|---|---|
| 自变量 x / 定义域 | 青 `#5CC8E8` |
| 函数值 y / 值域 | 金 `#FFD25A` |
| 函数 f、强调、犯规 | 构成红 `#E8553A` |
| 第二个函数 g / 正确 | 绿 `#7BD389` |
| 反函数 f⁻¹、辅助线 | 紫 `#B79CFF` |
| 文字、坐标轴 | 米白 `#EDE6D8` |
| Claude / GPT 标签 | 橙 `#E8833A` / 蓝 `#4A8FE7` |

**版式**：16:9；讲师立绘在左约 28% 宽，右侧是数学工作区（常驻 L1）；定义/定理用发光公式直接写在工作区，讲完缩到角落留作“板书”，不加卡片底。公式 ≥ 64 px；字幕单行优先，深色半透明底条。

**禁止**：整页静止讲话；强闪光和高频黑白切换；立绘说话抖动；星空快速移动或高亮闪烁；同屏超过 3 种强调色。

## 3.1 数学动画规范（目标：比 3B1B 更密、更好懂）

| 原则 | 具体要求 |
|---|---|
| 每个知识点有招牌动画 | 第 1 章 A01–A40（见大纲第 4 节），每段至少 4 个 |
| 画面始终在“讲数学” | 讲解时间里 ≥ 80% 的时长，工作区有数学对象在变化；每 ≤ 3 s 出现一个新的视觉事件 |
| 先动画、后公式 | 先让观众看到现象（放大、扫描、折叠），再把公式写出来对上 |
| 一次只变一件事 | 同时运动的主对象 ≤ 2 个；变化前的状态留半透明虚影作对照 |
| 参数可见 | 凡是有参数，就配滑杆 + 实时读数（a、h、k、M、n…） |
| 颜色即变量 | 严格按上面的颜色语义；同一个 x 在公式、图像、数轴上同色 |
| 连续而不切换 | 用变形（morph）、镜头推拉、平面翻转代替“换一页”；公式片段移动用符号变形（T） |
| 关键处放慢 | 每段只留 1 个“慢镜头”（如 A14 量词对战），其余快过 |
| 易懂优先于炫 | 每个动画审片时回答：去掉它，这一点会不会更难懂？答“不会”就删 |

**引擎数学组件包 `shared/math.js`（第 1 章需要）**：坐标系（可平移缩放的无限平面）、函数采样绘制（自适应步长、断点与渐近线处理、逐笔描出）、数轴与区间、映射图（集合椭圆 + 箭头）、粒子系统（确定性随机种子）、滑杆读数、伪 3D 平面翻转（投影矩阵）、本轮/级数、公式 SVG → Path2D（逐笔写出 + 片段变形）、单位圆、放大镜。

## 3.3 特效库（P0 v2 起，`shared/core.js` FX 段）

| 函数 | 效果 | 用在哪里 |
|---|---|---|
| `glowText` / `glowMath` | 光笔从左到右揭示 + 字面一道光扫 | 定义、术语、标签（替代卡片） |
| `kinetic` | 逐字飞入、回弹、带 3 帧运动拖影 | 标题、关键词 |
| `particleText` / `textPoints` | 粒子从别处飞来拼成字，再转实体发光字；可炸散退场 | 每段 1–2 个“关键词时刻”（映射、高中速通…） |
| `sparks` / `shock` / `burst` | 火花（减速 + 重力）/ 双环冲击波 | 落点、命中、揭示 |
| `flash` | 全屏闪白 | **只用于转场和全段唯一的高潮**，α ≤ 0.6，0.3 s 内衰减 |
| `warp` / `focusLines` | 曲速星流 / 集中线 | 时间跳跃、镜头放大 |
| `ghosts` | 运动拖影 | 快速移动的对象 |
| `PULSE` | 重音时星空亮一下 | 自动，跟音效表联动 |

使用规则：每个视觉事件最多叠 2 种特效；冲击波/火花跟着“有意义的落点”走，不做装饰性连发；同屏最多 1 个粒子组字；粒子数 ≤ 900/组（1080p 单帧 ≤ 120 ms）。

## 3.4 音效与 BGM（10-26 反馈：“咚”太频繁）

| 类别 | 音色 | 次数上限 |
|---|---|---|
| **重击**（`stamp`、`impact`、`slam`、`thud`） | 低频“咚” | **每段 ≤ 2 次**，只给全段唯一的印章 / 最大的反转 |
| 柔和命中（`soft_hit`、`marimba`、`bell_soft`、`pluck`） | 木琴、软钟、拨弦 | 默认用于落点、出现、打勾 |
| 过渡（`swoosh_soft`、`swell`、`whoosh`） | 柔和气流、渐强 pad | 转场、飞入 |
| 点缀（`tick`、`tick2`、`type`、`sparkle`、`shimmer`） | 轻 | 不限，但 1 s 内同类 ≤ 4 个 |

- 音效总增益 ×0.5（`mix.py`），单个 gain 一般 0.3–0.6；重击才给到 0.8–1.0。
- BGM 选 **轻松、明亮、无人声** 的署名授权曲（CC BY 4.0 等可非商用），片尾署名；当前曲目见 `素材与授权.md`。不用风格沉重/科幻感太强的曲子。
- BGM 电平：归一 RMS 0.12 → ×0.30，遇人声压到 40%；纯 BGM 段约 −28 LUFS（比人声低 ≈ 12 dB）。

## 3.2 代码式动画（JavaScript）

两种用法，都只在合适时用：

1. **程序生成的动画**（主要用法）：粒子流（A09/A10/A19）、本轮（A02）、稠密尘埃（A01）、生成树（A35）、星空本身。全部用固定随机种子，保证 `renderAt(t)` 确定、任意帧可重渲。
2. **屏幕上的代码**（点缀用法）：把“函数 = 程序”当作函数的第五种表示。代码窗打字机出现，运行时当前行高亮，旁边的数学对象同步变化（A04 `isRational`、A20 复合管道）。代码一律用 JavaScript 箭头函数，短于 3 行，字幕给中文解释。不讲编程语法本身。

不引入大型动画库，保持 Git 课“纯 Canvas + 时间纯函数”的路线；若后续章节需要真 3D（曲面、旋转体），再评估 three.js（同样可以做 `renderAt(t)`）。

## 4. 角色与配音

| 角色 | 定位 | 性格基调（社区印象，台词原创，不拉踩） | 配音 | 立绘 |
|---|---|---|---|---|
| Claude | 主讲，连续讲解 | 成熟御姐、严谨温和、爱书，讲究“先定义再下结论” | GPT-SoVITS 克隆，参考音 Git 课 `audio/ref_squad/c_ref.wav`（御姐 v3） | 现有 `c_base / c_ok / c_cool`，需补 6 张：讲解、指图、写板、思考、微笑、惊讶 |
| GPT | 辅讲，给快招/检验法/补充 | 白发龙娘，见多识广、略带傲气的“老前辈”，一句话点破 | GPT-SoVITS，按用户要求用 Git 课训练/克隆的声线（`audio/ref_g/`） | **待生成**：ai-girls `gpt/adult` 白发龙娘设定，首批 5 张：基础、指点、得意、抱臂、惊讶 |
| 大肥鱼 | 主要学生，每个知识点提 1 问 | 好奇、容易慌、爱摸鱼、偷吃白饭 | GPT-SoVITS 零样本，参考音 Git 课 `audio/ref/` | 现有 10 张 `d_*` 直接用 |
| 其他 AI 娘 | 客串，每人对应一个知识点或一个坑 | 同 Git 课第 3 集设定 | 同 Git 课 | 同 Git 课 |

**结构**：一问一讲——大肥鱼 1 问（或 1 次翻车）→ Claude 连续讲 → GPT 最多 1 段快招/反例 → 大肥鱼 1 句反应。不来回插话。

**双语术语**：课件是英文教材，新术语第一次出现时在相关图形旁写一行发光术语（英文 F_MATH 青色 + 中文金色 + 下划光线，不加卡片），台词里中文为主，英文只在画面上。

**朗读稿规则（数学专用）**：字幕写真实符号，朗读稿写读法。

| 字幕 | 朗读稿 |
|---|---|
| `x²` | x 的平方 |
| `f(x)` | f x |
| `A = πr²` | A 等于派 r 平方 |
| `√(4−x)` | 根号下四减 x |
| `x ≠ 1` | x 不等于一 |
| `(−∞, 4]` | 负无穷到四，包含四 |
| `f: D → E` | f 把 D 映到 E |
| `∀x` / `∃M` | 对任意 x / 存在 M |
| `sin⁻¹x`、`arcsin x` | 反正弦 x |
| `f∘g` | f 复合 g |
| `cosh x` | 双曲余弦 x |

字母读音先试 GPT-SoVITS 原样；读错的改写成谐音（如 x→“艾克斯”），并记入本表。

## 5. 质检清单（每次出片）

- [ ] `check_pace.py` 全部达标（第 2 节）
- [ ] 逐句 ASR：相似度 ≥ 0.85，⚠ 句人工复听
- [ ] **数学复核**：每条结论、每个例题由第二个 AI 按清单核对（定义是否严谨、例子是否成立、符号与读法一致）
- [ ] 联系表：逐句一帧，无遮挡、出框、溢出；公式与字幕不重叠（`ch1/tools/shots.py` 截图）
- [ ] 客串角色在场时，内容不越过 x ≈ 1460；不得在 scenes 里另画客串立绘（统一由 kit `sideChars` 画，避免双影）
- [ ] 素材只从本项目目录复制，`build.sh` 不引用其他课程路径
- [ ] 响度 −16 LUFS 左右，峰值 ≤ −1.5 dBTP
- [ ] 重击音（stamp/impact/slam/thud）每段 ≤ 2 次；BGM 署名已上片尾
- [ ] 新增花字汉字已重新子集化字体
- [ ] 立绘逐张数手、头顶完整
- [ ] 动画自查：每个招牌动画都能回答“它让哪一点更好懂”；同屏强调色 ≤ 3；星空不抢视线

## 6. 相对 Git 课的工程改进（开工时一并做）

1. **引擎拆成公共内核 + 场景**：Git 课三集各拷一份 `engine.js`（ep3 已 1396 行，三份已分叉）。微积分课从 P1 起改为 `ch1/shared/core.js`（时间工具、星空、立绘、字幕、文字组件、特效库、音效登记、渲染入口）+ 每段 `seg.js`（台词计划、立绘表）+ `scenes.js`（该段场景与音效）。P0 已交付，保留单文件 `ch1/web/engine.js` 不再改动。
2. **分段渲染 + NVENC**：60 分钟单进程逐帧导出约需 1 小时以上。`render.py` 已支持 `--start/--end`，改成按块多进程并行，最后无损拼接；编码可用本机 RTX 5070 的 `h264_nvenc`。
3. **节奏自动检查**：见第 2 节 `check_pace.py`。
4. **全章按大纲分 8 段（长度不等）**：每段一个 `PLAN` 块组、独立渲染与审片，B 站可按分 P 发布；改一段不必重出全片。
5. **纳入 Git 管理**：同 Git 课 `.gitignore`（`out/`、`vo48/` 不进库）。
