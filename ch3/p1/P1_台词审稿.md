## 数值核对

| 量 | 值 |
|---|---|
| (2ˣ)′ | 2ˣ ln 2，ln 2 ≈ 0.6931，所以“约等于 0.69” |
| 三角循环 | sin → cos → −sin → −cos → sin（四阶导数回到自身） |
| sin 3x | (sin 3x)′ = 3cos 3x |
| (3x − 1)² | 2(3x − 1) · 3 = 6(3x − 1) = 18x − 6；展开 9x² − 6x + 1 求导也是 18x − 6 ✓ |
| 随堂 1 | (ln x)′ = 1/x，x = 1 时为 1 |
| 随堂 2 | (sin 2x)′ = 2cos 2x，x = 0 时 2cos 0 = 2 |
| e | e ≈ 2.71828，C11 说“2.718” |

## 朗读稿检查

- 字母：字幕里的 e 在朗读稿中都换成“自然指数函数”，ln 都换成“自然对数”；单独的 x 照念（前两章通过）。D02 朗读稿没有字母，意思和字幕一致。
- 多音字：“只记得一半”的“得”读 de；“背过”“只会背”的“背”读 bèi；“记一辈子”没有问题。
- 句首没有单字母 a / o / e。
- K04 的“月亮的圆缺”贴 Kimi 的月亮元素；K06 贴“长上下文 / 过目不忘”的人设。
