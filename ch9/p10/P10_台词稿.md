| 编号 | 角色 / 立绘 | 字幕 | 朗读（不同时） |

| C01 | Claude / c_explain | 同济补充：形如 dy/dx = φ(y/x) 的方程，叫齐次方程。 | 同济教材的补充。如果导数只依赖于 y 除以 x，这种方程叫齐次方程。 |

## 换元求解

| 编号 | 角色 / 立绘 | 字幕 | 朗读（不同时） |
|---|---|---|---|
| C03 | Claude / c_explain | 例：y′ = y/x + x/y，y(1) = 2。 | 看一个例子。导数等于 y 比 x，加上 x 比 y，初值在一处等于二。 |
| H02 | 混元 / h_calc | 换元：u + xu′ = u + 1/u，两边的 u 消掉了。 | 换元以后，u 加 x 乘 u 的导数，等于 u 加 u 分之一。两边的 u 消掉了。 |
| C04 | Claude / c_point | 分离：u du = dx/x，积分得 u²/2 = ln x + C。 | 分离变量，u du 等于 x 分之 dx。积分得到二分之 u 方，等于 ln x 加常数。 |
| G01 | GPT / gp_explain | 换回 y：y² = x²(2 ln x + C)；代入 y(1) = 2，C = 4。 | 换回原来的变量，y 方等于 x 方乘以，二倍 ln x 加常数。代入初值，常数等于四。 |
| H03 | 混元 / h_base | 所以 y = x√(2 ln x + 4)。计算器验算通过！ | 所以 y 等于 x 乘以根号下，二倍 ln x 加四。计算器验算通过！ |
